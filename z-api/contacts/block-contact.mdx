## Conceituação

Método que bloqueia ou desbloqueia um contato. Envie `phone` e `action`, que é `block` para bloquear ou `unblock` para desbloquear.

O `phone` é obrigatório e tem de 8 a 15 dígitos, só números, com código do país e DDD. Um LID, como `999999999999999@lid`, não é aceito. Fora dessas regras, a resposta é `400` com `phone is required`, `phone must contain only digits, with country and area code` ou, para uma `action` diferente de `block` e `unblock`, `action must be block or unblock`.

A resposta de sucesso é `200` com `{ "value": true }`, inclusive quando o contato já estava no estado pedido.
