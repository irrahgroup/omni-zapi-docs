## Conceituação

Método que informa se um número tem conta no WhatsApp. Informe o telefone no caminho, no formato DDI DDD NÚMERO, como `551199999999`.

Use para validar números, geralmente em formulários. Para verificar vários números de uma vez, use [Verificação em lote](/z-api/contacts/get-iswhatsapp-batch).
