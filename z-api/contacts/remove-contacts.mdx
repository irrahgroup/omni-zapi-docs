## Conceituação

Método que remove contatos do WhatsApp da lista de contatos do celular. A rota usa o método `DELETE` com corpo: envie uma lista JSON com os telefones, no formato DDI DDD NÚMERO.

Como na Z-API, a rota só funciona para contas do WhatsApp que já receberam a atualização necessária. Sem isso, a operação não é concluída.
