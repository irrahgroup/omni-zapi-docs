## Conceituação

Método que verifica em lote se números têm conta no WhatsApp. É a versão em lote de [Número com WhatsApp?](/z-api/contacts/get-iswhatsapp): envie os números em `phones`, no formato DDI DDD NÚMERO.

Use para validar listas, geralmente em formulários. O corpo da requisição pode ter até 10 MiB.
