## Conceituação

Método que retorna as mensagens que estão na fila aguardando processamento, paginadas por `page` e `pageSize`.

A Z-API considera esta rota obsoleta. Para novas integrações, use [Fila](/z-api/queue/post-queue), com paginação por cursor.

<Warning>
  Fora do WhatsApp Web não há fila: `page` e `pageSize` são ignorados e `messages` vem sempre vazio.
</Warning>
