## Conceituação

Método que retorna as mensagens que estão na fila aguardando processamento, com paginação por cursor. Sem corpo, a primeira página é retornada.

Use o `pagingState` da resposta para buscar a próxima página e pare quando `hasMore` for `false`. `pageSize` tem padrão 20 e máximo 30.

<Warning>
  Fora do WhatsApp Web não há fila: o corpo não é lido e a resposta é sempre uma página vazia e última, com `messages` vazio, `pagingState` `null` e `hasMore` `false`.
</Warning>
