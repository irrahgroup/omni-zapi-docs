## Conceituação

Método para alterar a descrição do perfil do número de WhatsApp conectado ao canal. Envie o texto em `value`.

No WhatsApp Oficial, a descrição é o texto **Sobre** (`about`) do perfil.

<Warning>
  No WhatsApp Oficial, o texto tem de 1 a 139 caracteres, [limite da Meta](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles). Se a Meta recusar o valor, a resposta é `422` com `the channel provider refused the request`.
</Warning>
