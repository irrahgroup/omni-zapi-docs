## Conceituação

Método para alterar o nome do perfil do número de WhatsApp conectado ao canal. Envie o nome em `value`.

Funciona em canal **WhatsApp Web**. Para renomear o canal no {projectName}, use [Renomear canal](/z-api/profile/update-name).

<Warning>
  No WhatsApp Oficial, a rota responde `422` com `profile name changes on META_WHATSAPP channels require Meta review: use WhatsApp Manager`. A mudança do nome de exibição passa por uma nova [análise da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/display-names).
</Warning>
