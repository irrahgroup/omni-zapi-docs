## Conceituação

Método para renomear o canal no {projectName}, o nome que aparece no painel. Envie o novo nome em `value`, com até 255 caracteres. A rota funciona em qualquer tipo de canal e não altera o nome do perfil do WhatsApp: para isso, use [Atualizar nome do perfil](/z-api/profile/profile-name).

O nome precisa ser único no workspace. Um nome vazio, ou só com espaços, responde `400` com `name must not be empty`. Acima de 255 caracteres, a resposta é `400` com `name must have at most 255 characters`. Um nome já usado por outro canal do workspace responde `422` com `A channel with this name already exists in this workspace. Pick another one.`
