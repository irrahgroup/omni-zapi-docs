## Conceituação

Método para alterar a imagem de perfil do número de WhatsApp conectado ao canal. Envie em `value` a URL da imagem.

<Warning>
  No WhatsApp Oficial, `value` precisa ser uma URL `http` ou `https`: outro formato, como Base64, responde `422` com `profile picture on META_WHATSAPP channels must be an http or https URL`. A foto não pode ser removida: um `value` vazio responde `422` com `the profile picture cannot be removed on META_WHATSAPP channels`.
</Warning>
