<Warning>
  Esta rota **não envia** no Z-API Omni. Ela responde sempre `422`. Veja [Limitações e recusas](/z-api/limitations#envio-recusado).
</Warning>

Na Z-API, esta rota envia um produto do catálogo do WhatsApp Business. Por esta rota, o envio ainda não está disponível. Para o envio de produto pela API nativa, veja [Enviar produto](/messages/send-product).

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `422` | `product message is not available for this channel yet` | Sempre. Nada é enviado |
