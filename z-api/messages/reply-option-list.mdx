## Conceituação

Método para responder uma lista de opções, como se o contato tivesse tocado em uma das opções. Informe em `messageId` a mensagem da lista e em `responseOptionId` o `id` da opção escolhida, o mesmo definido para ela quando a lista foi montada.

O `messageId` é o id da mensagem no Omni Z-API, e o `phone` é obrigatório, como na Z-API, mas não é usado. Na resposta, `messageId` e `id` repetem o `messageId` informado.
