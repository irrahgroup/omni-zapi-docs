## Conceituação

Na Z-API, para responder citando uma mensagem, basta incluir o atributo `messageId` no body de um endpoint de envio.

<Warning>
  Na versão Z-API Compatibilidade, a resposta com citação **não está disponível**, nem no WhatsApp Oficial nem no WhatsApp Web. O atributo `messageId` é aceito nos envios, mas a mensagem chega ao cliente como uma mensagem comum, sem citar a original.
</Warning>

Se você está migrando da Z-API, o envio com `messageId` não falha: a API responde normalmente e a mensagem é entregue, só que sem a citação. Não use esse campo esperando que o cliente veja a mensagem original.

Nas rotas [`send-reaction`](/z-api/messages/send-reaction) e [`send-remove-reaction`](/z-api/messages/send-remove-reaction), o `messageId` tem outra função: ele identifica a mensagem que recebe a reação, e continua valendo.

## Como citar uma mensagem

Para enviar uma mensagem citando outra, use as rotas de mensagens do Omni Z-API com o campo `content.messageIdReply`. A citação funciona no canal WhatsApp Oficial (Meta Cloud API). Veja [Responder citando uma mensagem](/messages/introduction#responder-citando-uma-mensagem).

O atributo `privateAnswer` (resposta privada em grupos) da Z-API não é compatível com a API oficial e não está disponível nesta versão.
