<Warning>
  A resposta com citação **ainda não está disponível**. O atributo `messageId` é aceito nos envios,
  mas a mensagem chega ao cliente como uma mensagem comum, sem citar a original. Veja as
  [Limitações da API Oficial](/z-api/limitations).
</Warning>

## Conceituação

Na Z-API, para responder citando uma mensagem, basta incluir o atributo `messageId` no body de um endpoint de envio. Esta versão ainda não envia essa citação para o WhatsApp.

Se você está migrando da Z-API, o envio com `messageId` não falha: a API responde normalmente e a mensagem é entregue, só que sem a citação. Não use esse campo esperando que o cliente veja a mensagem original.

<Warning>
  O atributo `privateAnswer` (resposta privada em grupos) da Z-API **não é compatível** com a API oficial e não está disponível nesta versão.
</Warning>
