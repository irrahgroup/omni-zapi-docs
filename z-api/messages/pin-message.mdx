## Conceituação

Método para fixar ou desafixar uma mensagem em uma conversa. Em `messageAction`, informe `pin` para fixar ou `unpin` para desafixar.

Ao fixar, `pinMessageDuration` define por quanto tempo a mensagem fica fixada: `24_hours`, `7_days` ou `30_days`. Ao desafixar, esse campo não é usado. O `messageId` é o id da mensagem no Omni Z-API, e o `phone` é obrigatório, como na Z-API, mas não é usado. Na resposta, `messageId` e `id` repetem o `messageId` informado.
