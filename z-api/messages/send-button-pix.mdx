title: "Enviar botão Pix"
description: "Rota de botão Pix, recusada no Z-API Omni"
openapi: "/pt/z-api/openapi.json POST /send-button-pix"
---

<Warning>
  Esta rota **não envia** no Z-API Omni. Ela responde sempre `422`. Veja [Limitações e recusas](/z-api/limitations#envio-recusado).
</Warning>

Na Z-API, esta rota envia uma mensagem com um botão que copia a chave Pix. O WhatsApp Oficial não tem esse botão.

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `422` | `pix button is not supported for this channel` | Sempre. Nada é enviado |
