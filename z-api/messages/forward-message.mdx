## Conceituação

Método para reencaminhar uma mensagem existente. Informe em `messageId` a mensagem a reencaminhar e em `phone` o destinatário.

O `messageId` é o id da mensagem no Omni Z-API (no formato padrão de webhook, `message._id`). Os atributos `messagePhone` e `delayMessage` são aceitos por compatibilidade com a Z-API e não são usados: a mensagem é encontrada pelo `messageId`. Na resposta, `messageId` e `id` trazem o id da nova mensagem, e `zaapId` é um identificador gerado pela API.
