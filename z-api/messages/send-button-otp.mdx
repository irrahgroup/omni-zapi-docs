## Conceituação

Método para envio de uma mensagem de texto com um botão para copiar um código, como um código de verificação. Funciona em canal **WhatsApp Web**.

## Campos

| Campo | Uso |
|---|---|
| `phone` | Obrigatório. Telefone do destinatário. |
| `message` | Obrigatório. Texto da mensagem. |
| `code` | Obrigatório. Código copiado ao clicar no botão. |

Os campos `image` e `buttonText` da Z-API não são enviados ao destinatário.

<Warning>
  No WhatsApp Oficial, o botão de copiar código só existe em templates de autenticação. Veja as [Limitações da API Oficial](/z-api/limitations).
</Warning>
