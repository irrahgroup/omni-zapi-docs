## Conceituação

Método para responder um botão de uma mensagem enviada com [lista de botões](/z-api/messages/send-button-list), como se o contato tivesse clicado nele. Informe em `messageId` a mensagem que contém os botões e em `responseButtonId` o id do botão escolhido.

O `messageId` é o id da mensagem no Omni Z-API, e o `phone` é obrigatório, como na Z-API, mas não é usado. Na resposta, `messageId` e `id` repetem o `messageId` informado.
