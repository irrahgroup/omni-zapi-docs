## Conceituação

As rotas desta seção enviam mensagens pelo formato da Z-API, por canais WhatsApp Oficial (`META_WHATSAPP`) com assinatura ativa. Um canal de outro tipo ou sem assinatura ativa recebe `422`.

<Warning>
  Pela API oficial do WhatsApp, uma mensagem livre só pode ser enviada com a janela de conversa de 24 horas aberta. A janela abre quando o **cliente envia uma mensagem para você**. Fora dela, a conversa só começa com um [template aprovado pela Meta](/z-api/messages/send-template). Veja [Janela de conversa](/conversation-window).
</Warning>

## Formato da requisição

- O corpo é JSON (`Content-Type: application/json`) ou `application/x-www-form-urlencoded`.
- `phone` é obrigatório em todo envio: o telefone do destinatário, com DDI e DDD, por exemplo `5511999999999`.
- `delayMessage` e `delayTyping` aceitam até 15. Um valor maior vale 15.
- `customId` é um identificador seu, devolvido na resposta.

## Resposta da API

Um envio aceito responde `200` com a mesma estrutura da Z-API:

```json
{
  "zaapId": "3999984263738042930CD6ECDE9VDWSA",
  "messageId": "D241XXXX732339502B68",
  "id": "D241XXXX732339502B68"
}
```

O `customId` vem na resposta quando você o envia. `id` tem o mesmo valor de `messageId`.

<Note>
  A estrutura da resposta é a da Z-API: o código que já processa esses campos continua funcionando.
</Note>

### Armazene o messageId

Guarde o `messageId` devolvido: ele é o identificador da mensagem nas operações que se referem a ela, como [enviar reação](/z-api/messages/send-reaction).

## Erros comuns

Valem para toda rota de envio. As rotas de [instância](/z-api/instance/status) e as recusas de rota seguem o mesmo corpo `{"error": "<texto>"}`.

| Status | Resposta `error` | Quando |
|---|---|---|
| `400` | `phone is required` | `phone` ausente ou vazio |
| `400` | `invalid image: must be a valid URL or base64 data URI` | O campo de mídia não é uma URL `http`/`https` nem um Base64 com prefixo `data:`. O mesmo vale para `invalid video`, `invalid ptv`, `invalid audio` e `invalid document` |
| `400` | `Authorization invalid` ou `<ip> not allowed` | Falha de [autenticação](/z-api/authentication) |
| `400` | `ec2Id is empty for this instance` | O canal ainda não terminou de ser provisionado |
| `404` | `instance not found` | O `id` ou o `token` do path não existe |
| `422` | `instance middleware is not META_WHATSAPP` | O canal não é WhatsApp Oficial |
| `422` | `instance subscription is not active` | O canal está sem assinatura ativa |
| `422` | `Authorization invalid` ou `You are blocked, contact support.` | Falha de [autenticação](/z-api/authentication) |
| `422` | `message has no content this route can send` | O corpo não gera nenhuma mensagem que a rota envie |
| `422` | `this channel does not support sending messages yet` | O tipo do canal ainda não tem entrega |
| `502` | `failed to send message` | A plataforma de mensagens não aceitou o envio. Tente de novo em alguns instantes |

## Formatação de texto

Você pode formatar o texto das mensagens com os caracteres especiais do WhatsApp:

| Formatação | Sintaxe | Resultado |
|---|---|---|
| **Negrito** | `*texto*` | **texto** |
| _Itálico_ | `_texto_` | _texto_ |
| ~~Tachado~~ | `~texto~` | ~~texto~~ |
| `Monoespaçado` | `` ```texto``` `` | `texto` |
