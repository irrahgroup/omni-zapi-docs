### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `400` | `phone is required` | `phone` ausente ou vazio |
| `400` | `message is required` | `message` ausente, vazio ou só com espaços |
| `400` | `mentions are only allowed in groups` | `mentioned` em uma conversa que não é de grupo |
| `422` | `message editing is not supported for this channel` | `editMessageId` no corpo |
