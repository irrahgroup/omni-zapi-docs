Rota genérica de envio. O tipo da mensagem é decidido pelos campos do corpo: com `image` é imagem, com `video` é vídeo, com `latitude` e `longitude` é localização, e assim por diante. Sem nenhum desses campos, é texto, com `message`. Prefira a rota específica de cada tipo.

<Note>
  <ZapiResponseText lang="pt" />
</Note>

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `400` | `phone is required` | `phone` ausente ou vazio |
| `422` | `message has no content this route can send` | `message` vazio ou só com espaços e nenhum outro conteúdo |
