## Conceituação

Método para apagar uma mensagem de um chat, seja uma mensagem que o canal enviou ou uma recebida do contato. Você só precisa do `messageId` da mensagem, que é o id dela no Omni Z-API: o mesmo que chega no webhook (no formato padrão, `message._id`).

A mensagem é sempre apagada para todos. Se `deleteForMe` for `true` ("apagar para mim"), a API responde `422`: envie `deleteForMe=false` ou omita o parâmetro. O `phone` é obrigatório, como na Z-API, mas não é usado: a mensagem é encontrada pelo `messageId`. O parâmetro `owner` é aceito e também não é usado.

O `200` indica que o pedido foi aceito. A exclusão no WhatsApp é feita em seguida.
