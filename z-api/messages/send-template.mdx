Envia um template aprovado. É a forma de iniciar uma conversa fora da janela de 24 horas. Veja [Templates](/templates/introduction).

<Note>
  <ZapiResponseText lang="pt" />
</Note>

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `400` | `phone is required` | `phone` ausente ou vazio |
| `400` | `template name is required` | `template.name` ausente ou vazio |
| `400` | `template language code is required` | `template.language.code` ausente ou vazio |
