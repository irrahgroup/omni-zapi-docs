Envia uma reação com emoji a uma mensagem. Informe o `messageId` da mensagem que recebe a reação.

<Note>
  <ZapiResponseText lang="pt" />
</Note>

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `400` | `phone is required` | `phone` ausente ou vazio |
| `422` | `messageId is required to react to a message` | `messageId` ausente ou vazio |
| `422` | `reaction is required` | `reaction` ausente ou vazio |
| `422` | `reaction must be an emoji` | `reaction` tem espaços, letras ou é longo demais para ser um emoji |
