## Conceituação

Método para responder um botão de uma mensagem enviada com [botões de ação](/z-api/messages/send-button-actions), como se o contato tivesse clicado nele. Informe em `messageId` a mensagem que contém os botões e em `responseTemplateButtonId` o id do botão escolhido. Só botões do tipo `REPLY` podem ser respondidos.

O `messageId` é o id da mensagem no Omni Z-API, e o `phone` é obrigatório, como na Z-API, mas não é usado. Na resposta, `messageId` e `id` repetem o `messageId` informado.
