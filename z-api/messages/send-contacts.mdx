## Conceituação

Método para envio de vários contatos em uma única mensagem. Não é necessário que os contatos estejam salvos na sua agenda: basta informar o nome e o telefone de cada um. Funciona em canal **WhatsApp Oficial** e em canal **WhatsApp Web**.

## Campos

| Campo | Uso |
|---|---|
| `phone` | Obrigatório. Telefone do destinatário. |
| `contacts` | Obrigatório. Lista dos contatos a enviar. |
| `contacts[].contactName` | Obrigatório. Nome do contato. |
| `contacts[].contactPhone` | Telefone do contato. Obrigatório quando `contactPhones` não é enviado. |
| `contacts[].contactPhones` | Lista de telefones do contato. Quando enviada, vale no lugar de `contactPhone`. |

<Warning>
  Cada item de `contacts` usa os nomes `contactName`, `contactPhone` e `contactPhones`, os mesmos do [`send-contact`](/z-api/messages/send-contact). Os nomes `name`, `phones` e `businessDescription` do envio de múltiplos contatos da Z-API não são lidos.
</Warning>
