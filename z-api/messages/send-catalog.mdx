<Warning>
  Esta rota **não envia** no Z-API Omni. Ela responde sempre `422`. Veja [Limitações e recusas](/z-api/limitations#envio-recusado).
</Warning>

Na Z-API, esta rota envia o catálogo de produtos do WhatsApp Business. Por esta rota, o envio ainda não está disponível. Para o envio de catálogo pela API nativa, veja [Enviar catálogo](/messages/send-catalog).

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `422` | `catalog message is not available for this channel yet` | Sempre. Nada é enviado |
