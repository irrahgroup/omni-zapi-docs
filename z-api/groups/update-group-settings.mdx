## Conceituação

Método que altera as preferências do grupo.

Somente administradores podem alterar as preferências do grupo.

<Warning>
  No WhatsApp Oficial esta rota não está disponível e responde `422`. A [Meta só define a aprovação de entrada na criação do grupo](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group): para isso, use `requireAdminApproval` em [Criar grupo](/z-api/groups/create-group).
</Warning>
