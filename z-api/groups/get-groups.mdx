## Conceituação

Método que retorna os grupos do canal. Use o campo `phone` de cada item como ID do grupo nas demais rotas desta seção.

Informe `page` e `pageSize` para paginar o resultado.

<Warning>
  No WhatsApp Oficial, a lista traz os [grupos ativos do número](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-active-groups) na Groups API da Meta, e `page` e `pageSize` são opcionais (valem `1` e `10`).
</Warning>
