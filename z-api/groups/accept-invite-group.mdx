## Conceituação

Método que aceita um convite recebido para participar de um grupo. A URL do convite pode ser obtida pelo webhook de mensagem recebida.

<Warning>
  No WhatsApp Oficial esta rota não está disponível e responde `422`: a [Groups API da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference) não tem rota equivalente.
</Warning>
