## Conceituação

Método que retorna o metadata do grupo, com todas as informações do grupo e de seus participantes, exceto o link de convite.

A única diferença para o [Metadata do grupo](/z-api/groups/group-metadata) é que este não retorna o link de convite, porque em certos momentos obter o link é custoso e um pouco demorado. Se precisar do link, use [Obter link de convite](/z-api/groups/group-invitation-link).

<Warning>
  No WhatsApp Oficial, os campos têm os mesmos valores de [Metadata do grupo](/z-api/groups/group-metadata), com `invitationLink` sempre `null`.
</Warning>
