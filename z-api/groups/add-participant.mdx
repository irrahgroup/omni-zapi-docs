## Conceituação

Método que adiciona novos participantes ao grupo.

Para incluir participantes, use somente o número de telefone. O identificador `@lid` não é compatível e não adiciona o membro.

<Warning>
  No WhatsApp Oficial esta rota não está disponível e responde `422`: a [Meta não permite adicionar participantes manualmente](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group), e a entrada é só pelo link de convite. Obtenha o link com [Obter link de convite](/z-api/groups/group-invitation-link) e compartilhe com o contato.
</Warning>
