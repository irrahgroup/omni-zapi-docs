## Conceituação

Método que redefine o link de convite de um grupo. A rota não recebe corpo: o grupo vai no caminho.

<Warning>
  No WhatsApp Oficial, o [link anterior deixa de valer](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-and-reset-group-invite-link) e a resposta traz só `invitationLink`, com o link novo.
</Warning>
