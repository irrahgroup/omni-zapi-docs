## Conceituação

Método que altera a descrição de um grupo.

Somente administradores podem alterar as preferências do grupo.

<Warning>
  No WhatsApp Oficial, `groupDescription` tem até 2048 caracteres ([limite da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#update-group-settings)). `{"value": true}` é o aceite da Meta, não a confirmação de que a alteração já apareceu no grupo.
</Warning>
