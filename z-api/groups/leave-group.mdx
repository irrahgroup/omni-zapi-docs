## Conceituação

Método que faz o número conectado sair de um grupo do qual participa.

<Warning>
  No WhatsApp Oficial, a [Groups API da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group) não tem a ação de sair do grupo, só a de excluir o grupo, que remove todos os participantes, inclusive a empresa. Esta rota não a faz: o grupo não é excluído.
</Warning>
