## Conceituação

Método que promove participantes do grupo a administradores. Você pode promover um ou mais participantes.

<Warning>
  No WhatsApp Oficial esta rota não está disponível e responde `422`: a empresa é a criadora e [administradora do grupo](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference), e a Groups API da Meta não tem rota para promover ou remover administradores.
</Warning>
