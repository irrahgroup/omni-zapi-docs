## Conceituação

Método que retorna os produtos do catálogo do WhatsApp Business do canal. Informe `nextCursor` para buscar mais registros.

Se o `nextCursor` ficar grande demais para a URL, use [Pegar produtos V2](/z-api/catalog/get-products-v2), que recebe o cursor no corpo da requisição.
