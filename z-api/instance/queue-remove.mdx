---
title: "Apagar uma mensagem da fila"

openapi: "/pt/z-api/openapi.json DELETE /queue/{zaapId}"
---

## Conceituação

Responde `422` e não remove nada: uma mensagem enviada já foi entregue à API oficial e não pode ser retirada.

```json
{
  "error": "messages are not queued on META_WHATSAPP channels: they are handed to the official API when sent and cannot be removed"
}
```

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `422` | `messages are not queued on META_WHATSAPP channels: they are handed to the official API when sent and cannot be removed` | Sempre |
| `404` | `instance not found` | O `id` ou o `token` do path não existe |
| `422` | `queue route is not available through this compatibility route for Z_API_WHATSAPP instances yet` | O canal é do tipo `Z_API_WHATSAPP` |

Os erros de [autenticação](/z-api/authentication) valem aqui também.
