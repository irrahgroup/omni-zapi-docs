## Conceituação

Na Z-API, a fila guarda as mensagens que ainda não saíram. No WhatsApp Oficial, a mensagem é entregue à API oficial no momento do envio, então não há fila por canal. Esta rota existe para o seu código da Z-API continuar funcionando e responde sempre vazio. O corpo (`pageSize`, `pagingState`) não é lido.

```json
{
  "messages": [],
  "pagingState": null,
  "hasMore": false
}
```

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `404` | `instance not found` | O `id` ou o `token` do path não existe |
| `422` | `queue route is not available through this compatibility route for Z_API_WHATSAPP instances yet` | O canal é do tipo `Z_API_WHATSAPP` |

Os erros de [autenticação](/z-api/authentication) valem aqui também.
