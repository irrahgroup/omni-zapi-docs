## Conceituação

Método que informa se o canal está conectado. A resposta traz `connected`, o texto `error` com o detalhe do estado e `smartphoneConnected`.

O status considera só a conexão do canal. A situação da assinatura não entra nele.

<Warning>
  Fora do WhatsApp Web não há celular conectado, então `smartphoneConnected` sempre acompanha `connected`.
</Warning>
