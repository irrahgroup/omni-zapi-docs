## Conceituação

Devolve os dados do canal no formato da Z-API. Só vêm os campos que o Z-API Omni tem: um campo sem valor é omitido, nunca inventado.

```json
{
  "id": "019E4C54B1B375A28970B605CA9B03C3",
  "token": "F1B29C3D4E5A6B7C8D9E0F1A2B3C4D5E",
  "name": "Loja",
  "connected": true,
  "paymentStatus": "PAID"
}
```

| Campo | O que é |
|---|---|
| `id` | `id` do canal |
| `token` | `token` do canal |
| `name` | Nome do canal, quando existe |
| `due` | Vencimento, quando existe |
| `connected` | `true` quando o canal está conectado |
| `paymentStatus` | Situação do pagamento, quando existe |
| `created` | Data de criação, quando existe |

### Erros

| Status | Resposta `error` | Quando |
|---|---|---|
| `404` | `instance not found` | O `id` ou o `token` do path não existe |
| `422` | `instance data route is not available through this compatibility route for Z_API_WHATSAPP instances yet` | O canal é do tipo `Z_API_WHATSAPP` |
| `502` | `failed to read instance data` | A plataforma não respondeu. Tente de novo |

Os erros de [autenticação](/z-api/authentication) valem aqui também.
