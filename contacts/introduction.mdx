## Conceituação

Rotas de contato da API nova, em `/v1/channels/{channelId}/contacts`. Disponíveis **só no canal WhatsApp Web** (`Z_API_WHATSAPP`): listar, consultar, foto, verificar números e capacidades.

<Note>
  No canal Meta (`META_WHATSAPP`), estas rotas respondem `422` — a API oficial não dá acesso aos contatos do número. A rota de [capacidades](/contacts/capabilities) responde `200` com a lista de operações vazia.
</Note>

<Note>
  As escritas (adicionar, remover e denunciar contato) chegam numa próxima fase e hoje respondem `422`.
</Note>

A autenticação é a [Secret Key](/authentication). Só o caminho `/v1/channels/{channelId}/...` é atendido; os prefixos `/instances` e `/devices` respondem `404`.
