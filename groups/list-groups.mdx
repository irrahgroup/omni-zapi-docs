## Conceituação

Lista paginada dos grupos do número.

<Note>
  A paginação é por cursor opaco: devolva o `nextCursor` como veio para a próxima página. O `pageSize` é 20 por padrão, sem máximo (inteiro positivo de até 9 dígitos). O `nextCursor` só vem nulo quando a página tem menos itens que o `pageSize` — uma última página com exatamente `pageSize` itens é seguida por uma página vazia. O cursor de grupos (`g1:`) não serve para contatos.
</Note>
