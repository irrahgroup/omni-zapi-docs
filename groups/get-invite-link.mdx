## Conceituação

Link de convite do grupo.

<Note>
  O **canal** precisa ser administrador do grupo; senão, `422` `provider_error` com a mensagem `The channel is not an admin of this group, so WhatsApp does not return its invite link. Make the channel an admin of the group, or ask a group admin for the link.`
</Note>
