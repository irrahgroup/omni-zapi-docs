title: "WhatsApp Web status and device"
description: "Check whether a WhatsApp Web channel is connected and which device is linked"
---

Two read routes for `Z_API_WHATSAPP` (WhatsApp Web) channels. Both use the Secret Key in the `Authorization: Bearer YOUR_SECRET_KEY` header. Always call them from the backend. See [Authentication](/en/authentication).

The QR code flow is in [Connect WhatsApp Web](/en/connect/whatsapp-web).

## Routes

| Page | Route | What it is for |
|---|---|---|
| [Get WhatsApp Web status](/en/channels/get-whatsapp-web-status) | `GET /v1/channels/{channelId}/zapi/status` | Know whether the QR code was scanned and the number is connected |
| [Get WhatsApp Web device](/en/channels/get-whatsapp-web-device) | `GET /v1/channels/{channelId}/zapi/device` | Know which number and which device are linked to the channel |

## Errors

Both routes respond with the same errors:

| Status | Body | When it happens |
|---|---|---|
| `401` | `{"error": "Authorization invalid", "message": "..."}` | The Secret Key was refused. See the reasons in [Authentication](/en/authentication) |
| `403` | `{"error": "ip_not_allowed", "message": "..."}` | The source IP is off the list. See [IP restriction](/en/security/ip-restriction) |
| `404` | `{"error": "Instance not found"}` | The channel does not exist or belongs to another workspace |
| `422` | `{"error": {"errors": [{"code": "413", ...}]}}` | The channel is not WhatsApp Web (`error.errors[0].code` `"413"`, `name` `IS_NOT_Z_API_WHATSAPP_CHANNEL`). The `status` inside the body is `400`, but the `422` of the response is the one that counts |
| `422` | `{"error": { ... }}` or `{"error": "..."}` | Any other case: the provider refused the request. The `error` field carries the provider envelope or, without an envelope, a generic text |
| `502` | `{"error": "integration_unavailable", "message": "..."}` | An internal service is unavailable. Try again in a few moments |

Example of the `422` when the channel is not WhatsApp Web:

```json
{
  "error": {
    "timestamp": "2026-10-22T14:00:00.123Z",
    "status": 400,
    "errors": [
      {
        "code": "413",
        "name": "IS_NOT_Z_API_WHATSAPP_CHANNEL",
        "message": "Not a Z-API WhatsApp channel",
        "description": "The channel is not of type Z_API_WHATSAPP"
      }
    ]
  }
}
```

To disconnect the number, see [Disconnect channel](/en/channels/disconnect).
