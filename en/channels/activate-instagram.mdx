## Overview

Finishes the connection of a `META_INSTAGRAM` channel in your backend, after the SDK's `client.connect()`. See the [activation overview](/en/channels/activate-channel) for the full flow, the body built from the SDK, the timeout and the errors common to the activation routes.

## Request body

| Field | Type | Description |
|---|---|---|
| `code` | string | `code` returned by the SDK. Required |
| `redirectUri` | string | `redirectUri` returned by the SDK. Required |

Without `code` or without `redirectUri`, the API responds `422`.

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/CHANNEL_ID/activate-instagram \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SECRET_KEY" \
  -d '{
    "code": "CODE_FROM_SDK",
    "redirectUri": "REDIRECT_URI_FROM_SDK"
  }'
```

## Response

`200` response:

```json
{
  "id": "17841400000000000",
  "connected": true,
  "username": "mystore",
  "name": "My Store",
  "displayName": "My Store"
}
```

## Errors

The errors common to the activation routes (`401`, `403`, `404`, `422`, `502` and `504`) are in [Errors](/en/channels/activate-channel#errors). Activating a channel that is already active responds `422`, with `INSTAGRAM_META_IS_ALREADY_ACTIVATED` in the `error` field: see [Channel already active](/en/channels/activate-channel#channel-already-active).
