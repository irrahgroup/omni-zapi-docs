## Overview

Returns a channel from the workspace of your Secret Key, with the same fields as the listing plus the webhooks registered on it — id, URL and events of each endpoint.

<Warning>
  <EnterpriseText lang="en" />
</Warning>

<Note>
  A channel from another workspace returns `404`, the same as a channel that does not exist. The response does not distinguish between the two cases on purpose.
</Note>

### Webhooks

Unlike Z-API, where each instance has a fixed URL per callback type, in Omni a channel can have several endpoints, each subscribed to the events you choose. To create, update or delete them, use the [channel webhook](/en/webhooks/channel-webhooks) routes.

<Note>
  The `channelId` comes from the [Create channel](/en/channels/create-channel) endpoint or from [List channels](/en/channels/list-channels).
</Note>
