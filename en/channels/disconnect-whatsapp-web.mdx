## Overview

Disconnects the number of a `Z_API_WHATSAPP` (WhatsApp Web) channel. The route has no body. To turn the channel on again, scan the QR code again, as in [Connect WhatsApp Web](/en/connect/whatsapp-web).

## Example

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/CHANNEL_ID/zapi/disconnect \
  -H "Authorization: Bearer YOUR_SECRET_KEY"
```

## Response

`200` with `true`:

```json
true
```

## Errors

The errors (`401`, `403`, `404`, `422` and `502`) are common to the disconnection routes and are in [Errors](/en/channels/disconnect#errors).
