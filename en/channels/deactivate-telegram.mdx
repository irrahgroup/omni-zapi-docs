## Overview

Disconnects a `BOT_TELEGRAM` channel. The route has no body and also marks the channel as disconnected. To turn the channel on again, see [Activate channel](/en/channels/activate-channel).

## Example

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/CHANNEL_ID/deactivate-telegram \
  -H "Authorization: Bearer YOUR_SECRET_KEY"
```

## Response

`200` with `true`:

```json
true
```

## Errors

The errors (`401`, `403`, `404`, `422` and `502`) are common to the disconnection routes and are in [Errors](/en/channels/disconnect#errors).
