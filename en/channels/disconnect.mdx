Each channel type has its own disconnection route. All of them use the Secret Key in the `Authorization: Bearer YOUR_SECRET_KEY` header. Always call them from the backend. See [Authentication](/en/authentication).

## Routes

| Channel type | Route |
|---|---|
| `META_WHATSAPP` | [`PUT /v1/channels/{channelId}/disconnect`](/en/channels/disconnect-meta-whatsapp) |
| `META_INSTAGRAM` | [`POST /v1/channels/{channelId}/deactivate-instagram`](/en/channels/deactivate-instagram) |
| `META_MESSENGER` | [`POST /v1/channels/{channelId}/deactivate-messenger`](/en/channels/deactivate-messenger) |
| `BOT_TELEGRAM` | [`POST /v1/channels/{channelId}/deactivate-telegram`](/en/channels/deactivate-telegram) |
| `Z_API_WHATSAPP` (WhatsApp Web) | [`POST /v1/channels/{channelId}/zapi/disconnect`](/en/channels/disconnect-whatsapp-web) |

The Instagram, Messenger, Telegram and WhatsApp Web routes use `POST` and have no body. All four respond `200` with `true`. The `deactivate-*` routes also mark the channel as disconnected.

## Turning it on again

To connect a Meta WhatsApp channel again, see [Connect channel](/en/channels/connect-channel). For Instagram, Messenger and Telegram, see [Activate channel](/en/channels/activate-channel). For WhatsApp Web, scan the QR code again, as in [Connect WhatsApp Web](/en/connect/whatsapp-web).

## Errors

The Instagram, Messenger, Telegram and WhatsApp Web routes respond with these errors:

| Status | Body | When it happens |
|---|---|---|
| `401` | `{"error": "Authorization invalid", "message": "..."}` | The Secret Key was refused. See the reasons in [Authentication](/en/authentication) |
| `403` | `{"error": "ip_not_allowed", "message": "..."}` | The source IP is off the list. See [IP restriction](/en/security/ip-restriction) |
| `404` | `{"error": "Instance not found"}` | The channel does not exist or belongs to another workspace |
| `422` | `{"error": { ... }}` or `{"error": "..."}` | The provider refused the disconnection. The `error` field carries the provider envelope or, without an envelope, a generic text |
| `502` | `{"error": "integration_unavailable", "message": "..."}` | An internal service is unavailable. Try again in a few moments |
