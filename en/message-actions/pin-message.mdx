## Overview

Pins the message in the chat.

<Note>
  `duration`: `24_HOURS`, `7_DAYS`, or `30_DAYS` (uppercase, exactly like this). Responds `204`, no body. A value outside these three responds `400` `{"error": "invalid_request", "field": "duration"}`.
</Note>
