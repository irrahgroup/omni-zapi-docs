## Overview

Method that returns the group metadata, with all the group information and its participants, except the invitation link.

The only difference from [Group metadata](/en/z-api/groups/group-metadata) is that this one does not return the invitation link, because getting the link is sometimes costly and slightly slow. If you need the link, use [Get invitation link](/en/z-api/groups/group-invitation-link).

<Warning>
  On WhatsApp Official, the fields have the same values as [Group metadata](/en/z-api/groups/group-metadata), with `invitationLink` always `null`.
</Warning>
