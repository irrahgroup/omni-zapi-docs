## Overview

Method that returns the group metadata, with all the group information and its participants, from the invitation link.

<Warning>
  On WhatsApp Official this route is not available and answers `422`: [Meta's Groups API](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference) has no equivalent route.
</Warning>
