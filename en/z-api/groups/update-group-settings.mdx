## Overview

Method that changes the group preferences.

Only administrators can change the group preferences.

<Warning>
  On WhatsApp Official this route is not available and answers `422`. [Meta only sets join approval when the group is created](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group): for that, use `requireAdminApproval` in [Create group](/en/z-api/groups/create-group).
</Warning>
