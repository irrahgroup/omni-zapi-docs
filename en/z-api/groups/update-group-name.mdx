## Overview

Method that changes the name of an existing group.

<Warning>
  On WhatsApp Official, `groupName` has 1 to 128 characters ([Meta limit](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#update-group-settings)). `{"value": true}` is Meta's acceptance, not confirmation that the change already appeared in the group.
</Warning>
