## Overview

Method that changes a group's description.

Only administrators can change the group preferences.

<Warning>
  On WhatsApp Official, `groupDescription` has up to 2048 characters ([Meta limit](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#update-group-settings)). `{"value": true}` is Meta's acceptance, not confirmation that the change already appeared in the group.
</Warning>
