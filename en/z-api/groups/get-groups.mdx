## Overview

Method that returns the channel's groups. Use the `phone` field of each item as the group ID in the other routes of this section.

Send `page` and `pageSize` to paginate the result.

<Warning>
  On WhatsApp Official, the list returns the [active groups of the number](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-active-groups) in Meta's Groups API, and `page` and `pageSize` are optional (they default to `1` and `10`).
</Warning>
