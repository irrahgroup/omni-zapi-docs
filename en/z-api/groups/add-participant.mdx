## Overview

Method that adds new participants to the group.

To add participants, use the phone number only. The `@lid` identifier is not supported and does not add the member.

<Warning>
  On WhatsApp Official this route is not available and answers `422`: [Meta does not allow adding participants manually](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group), and entry is only through the invitation link. Get the link with [Get invitation link](/en/z-api/groups/group-invitation-link) and share it with the contact.
</Warning>
