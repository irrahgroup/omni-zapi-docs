## Overview

Method that redefines a group's invitation link. The route takes no body: the group goes in the path.

<Warning>
  On WhatsApp Official, the [previous link stops working](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-and-reset-group-invite-link) and the response has only `invitationLink`, with the new link.
</Warning>
