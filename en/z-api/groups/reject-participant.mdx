## Overview

Method that rejects participants joining the group.

<Warning>
  On WhatsApp Official, this route only works for a group with [join approval](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#groups-with-join-requests), created with `requireAdminApproval` `true` in [Create group](/en/z-api/groups/create-group).
</Warning>
