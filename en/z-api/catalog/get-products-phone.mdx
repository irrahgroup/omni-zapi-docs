## Overview

Method that returns the products of the WhatsApp Business catalog of a number, whether it is the channel's or someone else's. Send `nextCursor` to fetch more records.

If `nextCursor` gets too large for the URL, use [Get products V2 (phone)](/en/z-api/catalog/get-products-phone-v2), which takes the cursor in the request body.
