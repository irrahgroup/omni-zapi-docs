## Overview

Method that returns the products of the channel's WhatsApp Business catalog. Send `nextCursor` to fetch more records.

If `nextCursor` gets too large for the URL, use [Get products V2](/en/z-api/catalog/get-products-v2), which takes the cursor in the request body.
