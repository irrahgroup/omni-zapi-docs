## About compatibility

What a Z-API route does in {projectName} depends on the **channel type**:

- **WhatsApp Web** (`Z_API_WHATSAPP`): through the compatibility route, the response is the same Z-API would give.
- **Official WhatsApp** (`META_WHATSAPP`): the official Meta API applies, which serves some routes and has no equivalent for others.

The tables below show, per feature, what each channel does:

| Term | Meaning |
|---|---|
| Yes | The route works on the channel. On WhatsApp Web, the response is the same Z-API would give. |
| Partly | The route works with limits, described in the cell itself. |
| Not yet | The route is not yet released on this channel through the compatibility route. It is rolling out gradually. |
| No | The route does not work on the channel, usually because the channel has no equivalent. Any further detail is in the cell itself. |

## Groups

<Info>
  On the official WhatsApp (Meta) channel, groups use the Groups API and require a verified Official Business Account (OBA). Group routes respond `422` on a number without OBA and on a coexistence number, which uses the WhatsApp Business app on the same number. When a group is created on Meta, no one is added: every phone comes back in `phonesNotAdded` and `autoInvite` is ignored. People join through the invite link or an approved join request. On the WhatsApp Web channel, all of them respond as Z-API.
</Info>

## Queue

<Info>
  On the official WhatsApp (Meta) channel, messages are not queued: they go to Meta's official API when sent. So the queue is always empty, and deleting the queue or a message in it responds `422`: the message has already left and cannot be removed.
</Info>

| Feature | Z-API Route | WhatsApp Web | Official Meta |
|---|---|---|---|
| Count queued messages | [`GET /queue/count`](https://developer.z-api.io/en/queue/get-queue) | Yes | Partly (always `0`) |
| List queue | [`POST /queue`](https://developer.z-api.io/en/queue/post-queue) | Yes | Partly (always empty) |
| List queue (deprecated) | [`GET /queue`](https://developer.z-api.io/en/queue/get-queue) | Yes | Partly (always empty) |
| Delete queue | [`DELETE /queue`](https://developer.z-api.io/en/queue/delete-queue) | Yes | No (responds `422`) |
| Delete queued message | [`DELETE /queue/{zaapId}`](https://developer.z-api.io/en/queue/delete-queue-id) | Partly (the `zaapId` returned by the send is not in the queue) | No (responds `422`) |
