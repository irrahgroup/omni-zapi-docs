## Overview

Method that returns the messages in the queue waiting to be processed, paginated by `page` and `pageSize`.

Z-API considers this route deprecated. For new integrations, use [Queue](/en/z-api/queue/post-queue), with cursor pagination.

<Warning>
  Outside WhatsApp Web there is no queue: `page` and `pageSize` are ignored and the response is always empty.

  The response format changes by channel. On WhatsApp Web, it is an array with the queued messages, as in Z-API (empty: `[]`). On WhatsApp Official, it is `{"messages": []}`, always empty.
</Warning>
