## Overview

Method that returns the messages in the queue waiting to be processed, with cursor pagination. Without a body, the first page is returned.

Use the `pagingState` from the response to get the next page and stop when `hasMore` is `false`. `pageSize` defaults to 20 and has a maximum of 30.

<Warning>
  Outside WhatsApp Web there is no queue: the body is not read and the response is always an empty, last page, with empty `messages`, `pagingState` `null` and `hasMore` `false`.
</Warning>
