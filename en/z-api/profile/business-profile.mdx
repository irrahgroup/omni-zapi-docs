## Overview

Method to get the WhatsApp Business profile data of the channel: description, address, email and websites and, on WhatsApp Web, also categories and business hours.

On WhatsApp Web, the `phone` query parameter is the same as in Z-API. On Official WhatsApp, the query always returns the profile of the channel's own number: `phone` is optional and, if sent, must be the channel's number. The fields follow the [business profile of Meta's official API](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles).

<Warning>
  On Official WhatsApp, the response contains only `description`, `address`, `email` and `websites`, and a field that Meta did not return is omitted. `categories`, `businessHours` and `hasCoverPhoto` are not returned. With the `phone` of another number, the response is `422` with `business profile of other numbers is not available for META_WHATSAPP channels`.
</Warning>
