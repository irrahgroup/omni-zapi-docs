## Overview

Method to update the profile name of the WhatsApp number connected to the channel. Send the name in `value`.

It works on **WhatsApp Web** channels. To rename the channel in {projectName}, use [Rename channel](/en/z-api/profile/update-name).

<Warning>
  On Official WhatsApp, the route responds `422` with `profile name changes on META_WHATSAPP channels require Meta review: use WhatsApp Manager`. A display name change goes through a new [Meta review](https://developers.facebook.com/documentation/business-messaging/whatsapp/display-names).
</Warning>
