## Overview

Method to update the company description in the WhatsApp Business profile. Send the text in `value`. On WhatsApp Web, an empty `value` removes the description, as in Z-API.

<Warning>
  On Official WhatsApp, the description has at most 512 characters, a [Meta limit](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles). If Meta refuses the value, the response is `422` with `the channel provider refused the request`.
</Warning>
