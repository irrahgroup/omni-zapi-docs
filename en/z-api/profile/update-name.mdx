## Overview

Method to rename the channel in {projectName}, the name shown in the dashboard. Send the new name in `value`, with up to 255 characters. The route works on any channel type and does not change the WhatsApp profile name: for that, use [Update profile name](/en/z-api/profile/profile-name).

The name must be unique in the workspace. An empty name, or one with only spaces, responds `400` with `name must not be empty`. Above 255 characters, the response is `400` with `name must have at most 255 characters`. A name already used by another channel in the workspace responds `422` with `A channel with this name already exists in this workspace. Pick another one.`
