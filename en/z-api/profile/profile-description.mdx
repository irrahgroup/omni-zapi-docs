## Overview

Method to update the description of the WhatsApp profile of the number connected to the channel. Send the text in `value`.

On Official WhatsApp, the description is the **About** text (`about`) of the profile.

<Warning>
  On Official WhatsApp, the text has from 1 to 139 characters, a [Meta limit](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles). If Meta refuses the value, the response is `422` with `the channel provider refused the request`.
</Warning>
