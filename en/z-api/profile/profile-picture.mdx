## Overview

Method to update the profile picture of the WhatsApp number connected to the channel. Send the image URL in `value`.

<Warning>
  On Official WhatsApp, `value` must be an `http` or `https` URL: any other format, such as Base64, responds `422` with `profile picture on META_WHATSAPP channels must be an http or https URL`. The picture cannot be removed: an empty `value` responds `422` with `the profile picture cannot be removed on META_WHATSAPP channels`.
</Warning>
