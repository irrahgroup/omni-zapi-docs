Generic send route. The message type is decided by the body fields: with `image` it is an image, with `video` a video, with `latitude` and `longitude` a location, and so on. With none of these fields, it is text, with `message`. Prefer the specific route for each type.

<Note>
  <ZapiResponseText lang="en" />
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `message has no content this route can send` | `message` empty or only spaces and no other content |
