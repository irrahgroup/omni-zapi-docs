Sends a message with up to 3 quick reply buttons. The recipient picks one, and the choice arrives as a reply.

<Note>
  <ZapiResponseText lang="en" />
</Note>

The size limits come from WhatsApp: a message of up to 1024 characters, 3 buttons, button text of up to 20 characters and an `id` of up to 256. When a limit is exceeded, the response is `422` with the field text, such as `message must be at most 1024 characters in a button list` or `buttonList.buttons[0].label must be at most 20 characters`. The body must carry `label` in each button: the old name `text` is not read.

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `message is required for a button list` | `message` missing or empty |
| `422` | `buttonList.buttons is required` | `buttonList.buttons` missing or empty |
| `422` | `buttonList.buttons must have at most 3 buttons` | More than 3 buttons |
| `422` | `buttonList.buttons[0].label is required` | Button without `label` (the number in brackets is the button position) |
| `422` | `buttonList.buttons labels must be unique` | Two buttons with the same `label` (the same applies to `id`: `buttonList.buttons ids must be unique`) |
| `422` | `buttonList accepts headerImage or headerVideo, not both` | `headerImage` and `headerVideo` together |
