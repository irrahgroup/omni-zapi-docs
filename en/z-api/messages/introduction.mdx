## Overview

The routes in this section send messages in the Z-API format, through WhatsApp Official channels (`META_WHATSAPP`) with an active subscription. A channel of another type, or without an active subscription, gets `422`.

<Warning>
  Through the official WhatsApp API, a free-form message can only be sent while the 24-hour conversation window is open. The window opens when the **customer sends you a message**. Outside it, a conversation can only start with a [template approved by Meta](/en/z-api/messages/send-template). See [Conversation window](/en/conversation-window).
</Warning>

## Request format

- The body is JSON (`Content-Type: application/json`) or `application/x-www-form-urlencoded`.
- `phone` is required on every send: the recipient phone, with country and area code, for example `5511999999999`.
- `delayMessage` and `delayTyping` accept up to 15. A larger value counts as 15.
- `customId` is an identifier of your own, returned in the response.

## API response

An accepted send answers `200` with the same structure as Z-API:

```json
{
  "zaapId": "3999984263738042930CD6ECDE9VDWSA",
  "messageId": "D241XXXX732339502B68",
  "id": "D241XXXX732339502B68"
}
```

`customId` comes back in the response when you send it. `id` has the same value as `messageId`.

<Note>
  The response structure is the Z-API one: the code that already processes these fields keeps working.
</Note>

### Store the messageId

Keep the returned `messageId`: it is the message identifier in the operations that refer to it, such as [send reaction](/en/z-api/messages/send-reaction).

## Common errors

They apply to every send route. The [instance](/en/z-api/instance/status) routes and the route refusals use the same body, `{"error": "<text>"}`.

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `400` | `invalid image: must be a valid URL or base64 data URI` | The media field is neither an `http`/`https` URL nor a Base64 with a `data:` prefix. The same applies to `invalid video`, `invalid ptv`, `invalid audio` and `invalid document` |
| `400` | `Authorization invalid` or `<ip> not allowed` | [Authentication](/en/z-api/authentication) failure |
| `400` | `ec2Id is empty for this instance` | The channel has not finished being provisioned |
| `404` | `instance not found` | The `id` or `token` in the path does not exist |
| `422` | `instance middleware is not META_WHATSAPP` | The channel is not WhatsApp Official |
| `422` | `instance subscription is not active` | The channel has no active subscription |
| `422` | `Authorization invalid` or `You are blocked, contact support.` | [Authentication](/en/z-api/authentication) failure |
| `422` | `message has no content this route can send` | The body produces no message this route sends |
| `422` | `this channel does not support sending messages yet` | The channel type has no delivery yet |
| `502` | `failed to send message` | The messaging platform did not accept the send. Try again in a few moments |

## Text formatting

You can format message text with the WhatsApp special characters:

| Formatting | Syntax | Result |
|---|---|---|
| **Bold** | `*text*` | **text** |
| _Italic_ | `_text_` | _text_ |
| ~~Strikethrough~~ | `~text~` | ~~text~~ |
| `Monospace` | `` ```text``` `` | `text` |
