## Overview

Method for sending several contacts in a single message. The contacts don't need to be saved in your address book: just provide the name and phone number of each one. It works on **Official WhatsApp** channels and on **WhatsApp Web** channels.

## Fields

| Field | Use |
|---|---|
| `phone` | Required. Recipient phone number. |
| `contacts` | Required. List of contacts to send. |
| `contacts[].contactName` | Required. Contact name. |
| `contacts[].contactPhone` | Contact phone number. Required when `contactPhones` is not sent. |
| `contacts[].contactPhones` | List of the contact's phone numbers. When sent, it applies instead of `contactPhone`. |

<Warning>
  Each item of `contacts` uses the names `contactName`, `contactPhone` and `contactPhones`, the same as [`send-contact`](/en/z-api/messages/send-contact). The names `name`, `phones` and `businessDescription` from the Z-API multiple contacts send are not read.
</Warning>
