Sends a contact. It does not need to be in your address book: provide the name and the phone.

<Note>
  <ZapiResponseText lang="en" />
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `message has no content this route can send` | `contactName` or `contactPhone` is missing |
