Sends a document, by **URL** or by **Base64**. The file extension goes in the path (`/send-document/pdf`).

<Note>
  <ZapiResponseText lang="en" />
</Note>

<Note>
  Size and format limits follow WhatsApp policies. See the [official WhatsApp documentation](https://developers.facebook.com/docs/whatsapp/api/media).
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `400` | `invalid document: must be a valid URL or base64 data URI` | The field is neither an `http`/`https` URL nor a Base64 with a `data:` prefix |
| `422` | `message has no content this route can send` | The body has neither the media field nor `message`, so there is nothing to send |
| `422` | `message editing is not supported for this channel` | `editDocumentMessageId` or `editMessageId` in the body |
