Sends an approved template. It is the way to start a conversation outside the 24-hour window. See [Templates](/en/templates/introduction).

<Note>
  <ZapiResponseText lang="en" />
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `400` | `template name is required` | `template.name` missing or empty |
| `400` | `template language code is required` | `template.language.code` missing or empty |
