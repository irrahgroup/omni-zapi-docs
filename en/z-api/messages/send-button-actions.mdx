Sends a message with buttons. A `URL` button opens a link. `REPLY` buttons are quick replies, as in [Send button list](/en/z-api/messages/send-button-list).

<Note>
  <ZapiResponseText lang="en" />
</Note>

The size and count limits come from WhatsApp. When a limit is exceeded, the response is `422` with the field text, such as `buttonActions[0].label must be at most 20 characters` or `title must be at most 60 characters`.

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `call button is not supported for this channel` | A button is of the `CALL` type |
| `422` | `only one URL button is supported for this channel` | More than one `URL` button |
| `422` | `title and footer with REPLY buttons are not available for this channel yet` | `REPLY` buttons with `title` or `footer` |
