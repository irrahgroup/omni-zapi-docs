## Overview

Method for sending a text message with a button to copy a code, such as a verification code. It works on **WhatsApp Web** channels.

## Fields

| Field | Use |
|---|---|
| `phone` | Required. Recipient phone number. |
| `message` | Required. Message text. |
| `code` | Required. Code copied when the button is clicked. |

The Z-API `image` and `buttonText` fields are not sent to the recipient.

<Warning>
  On Official WhatsApp, the copy code button only exists in authentication templates. See the [Official API Limitations](/en/z-api/limitations).
</Warning>
