Sends a verification code (OTP) message, with the `code` and the text in `message`.

<Note>
  <ZapiResponseText lang="en" />
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `message has no content this route can send` | `code` or `message` missing |
