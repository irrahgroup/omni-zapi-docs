Sends a simple text message. It supports WhatsApp formatting, emojis and line breaks.

</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `400` | `message is required` | `message` missing, empty or only spaces |
| `400` | `mentions are only allowed in groups` | `mentioned` in a conversation that is not a group |
| `422` | `message editing is not supported for this channel` | `editMessageId` in the body |
