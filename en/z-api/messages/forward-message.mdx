## Overview

Method for forwarding an existing message. Send the message to forward in `messageId` and the recipient in `phone`.

The `messageId` is the message id in Omni Z-API (in the default webhook format, `message._id`). The `messagePhone` and `delayMessage` attributes are accepted for compatibility with Z-API and are not used: the message is found by the `messageId`. In the response, `messageId` and `id` carry the id of the new message, and `zaapId` is an identifier generated by the API.
