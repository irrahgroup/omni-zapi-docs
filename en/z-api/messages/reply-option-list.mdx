## Overview

Method for answering an option list, as if the contact had tapped one of the options. Send the list message in `messageId` and the `id` of the chosen option in `responseOptionId`, the same one defined for it when the list was built.

The `messageId` is the message id in Omni Z-API, and `phone` is required, as in Z-API, but it is not used. In the response, `messageId` and `id` repeat the `messageId` you sent.
