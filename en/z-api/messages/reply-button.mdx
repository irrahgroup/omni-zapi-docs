## Overview

Method for answering a button of a message sent with a [button list](/en/z-api/messages/send-button-list), as if the contact had clicked it. Send the message that holds the buttons in `messageId` and the id of the chosen button in `responseButtonId`.

The `messageId` is the message id in Omni Z-API, and `phone` is required, as in Z-API, but it is not used. In the response, `messageId` and `id` repeat the `messageId` you sent.
