Sends an emoji reaction to a message. Provide the `messageId` of the message that gets the reaction.

<Note>
  <ZapiResponseText lang="en" />
</Note>

### Errors

| Status | `error` response | When |
|---|---|---|
| `400` | `phone is required` | `phone` missing or empty |
| `422` | `messageId is required to react to a message` | `messageId` missing or empty |
| `422` | `reaction is required` | `reaction` missing or empty |
| `422` | `reaction must be an emoji` | `reaction` has spaces, letters or is too long to be an emoji |
