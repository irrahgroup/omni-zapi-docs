---

<Warning>
  This route **does not send** on Z-API Omni. It always answers `422`. See [Limitations and refusals](/en/z-api/limitations#refused-sends).
</Warning>

On Z-API, this route sends a message with a button that copies the Pix key. WhatsApp Official does not have that button.

### Errors

| Status | `error` response | When |
|---|---|---|
| `422` | `pix button is not supported for this channel` | Always. Nothing is sent |
