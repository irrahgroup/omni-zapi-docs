## Overview

Method for pinning or unpinning a message in a conversation. In `messageAction`, send `pin` to pin or `unpin` to unpin.

When pinning, `pinMessageDuration` sets how long the message stays pinned: `24_hours`, `7_days` or `30_days`. When unpinning, this field is not used. The `messageId` is the message id in Omni Z-API, and `phone` is required, as in Z-API, but it is not used. In the response, `messageId` and `id` repeat the `messageId` you sent.
