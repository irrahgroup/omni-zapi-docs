<Warning>
  Quoted replies are **not available yet**. The `messageId` attribute is accepted in sends, but the
  message reaches the customer as a regular message, without quoting the original. See the
  [Official API Limitations](/en/z-api/limitations).
</Warning>

## Overview

In Z-API, to reply quoting a message, you include the `messageId` attribute in the body of a send endpoint. This version does not send that quote to WhatsApp yet.

If you are migrating from Z-API, a send with `messageId` does not fail: the API responds as usual and the message is delivered, only without the quote. Do not use this field expecting the customer to see the original message.

<Warning>
  The `privateAnswer` attribute (private reply in groups) from Z-API is **not compatible** with the official API and is not available in this version.
</Warning>
