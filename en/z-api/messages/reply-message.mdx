## Overview

In Z-API, to reply quoting a message, you include the `messageId` attribute in the body of a send endpoint.

<Warning>
  In the Z-API Compatibility version, quoted replies are **not available**, neither on Official WhatsApp nor on WhatsApp Web. The `messageId` attribute is accepted in sends, but the message reaches the customer as a regular message, without quoting the original.
</Warning>

If you are migrating from Z-API, a send with `messageId` does not fail: the API responds as usual and the message is delivered, only without the quote. Do not use this field expecting the customer to see the original message.

In the [`send-reaction`](/en/z-api/messages/send-reaction) and [`send-remove-reaction`](/en/z-api/messages/send-remove-reaction) routes, `messageId` has another role: it identifies the message that receives the reaction, and it still applies.

## How to quote a message

To send a message quoting another one, use the Omni Z-API message routes with the `content.messageIdReply` field. Quoting works on the Official WhatsApp channel (Meta Cloud API). See [Replying with a quote](/en/messages/introduction#replying-with-a-quote).

The `privateAnswer` attribute (private reply in groups) from Z-API is not compatible with the official API and is not available in this version.
