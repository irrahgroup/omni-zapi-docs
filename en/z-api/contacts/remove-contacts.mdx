## Overview

Method that removes WhatsApp contacts from the phone's contact list. The route uses the `DELETE` method with a body: send a JSON list with the phones, in the DDI DDD NUMBER format.

As in Z-API, the route only works for WhatsApp accounts that already received the required update. Without that, the operation is not completed.
