## Overview

Method that returns the metadata information of a contact: name, WhatsApp name, photo and profile about. Send the phone in the path, in the DDI DDD NUMBER format, such as `551199999999`.

The photo URL (`imgUrl`) is available for only 48 hours, per WhatsApp policy. To get the updated photo, use [Get contact picture](/en/z-api/contacts/get-profile-picture).

  <ZapiResponseText lang="en" />
</Note>

<Note>
  When the number does not exist on WhatsApp or is not in the address book of the channel's phone, the response is HTTP `200` with the body below, not an HTTP error. This behavior is inherited from Z-API: check the `statusCode` in the body.

  ```json
  {
    "message": "Phone not exists",
    "error": "Bad Request",
    "statusCode": 400
  }
  ```

  To check whether a number has WhatsApp, use [Number on WhatsApp?](/en/z-api/contacts/get-iswhatsapp) (`phone-exists`).
</Note>
