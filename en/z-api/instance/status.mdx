## Overview

Method that tells whether the channel is connected. The response has `connected`, the `error` text with the detail of the state, and `smartphoneConnected`.

The status considers only the connection of the channel. The subscription situation is not part of it.

<Warning>
  Outside WhatsApp Web there is no connected phone, so `smartphoneConnected` always follows `connected`.
</Warning>
