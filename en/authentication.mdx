## API Credentials

{projectName} uses a key pair: **Public Key** and **Secret Key**. Both are generated in the **Security** menu of the dashboard: [Security](https://app.omni.z-api.io/app/security).

---

## Public Key

The Public Key is used by the channel connection SDK ([`@omnizapi/connect`](https://www.npmjs.com/package/@omnizapi/connect)). With it, you can [connect channels](/en/channels/connect-channel) directly within your system, without needing to access the dashboard.

<Note>
  The Public Key can be exposed in your application's frontend, as it has limited permissions for channel connection only.
</Note>

Example usage:

```javascript
import OmniZapi from '@omnizapi/connect';

const client = OmniZapi.newClient({
  publicKey: 'YOUR_PUBLIC_KEY'
});
```

---

## Secret Key

The Secret Key is used for authentication in all {projectName} APIs. It must be sent in the `Authorization` header as a Bearer token in every request.

<Warning>
  The Secret Key must **never** be exposed in the frontend. Use it only in your application's backend.
</Warning>

Example usage:

```bash
curl -X GET https://api.omni.z-api.io/whatsapp/businesses \
  -H "Authorization: Bearer YOUR_SECRET_KEY"
```

---

## OAuth token of a connected app

An app connected to the workspace calls the API with `Authorization: Bearer <access_token>`. Whoever connects the app chooses the instances it reaches, and the token only sees and only acts on those instances:

- sending, reading the channel, Z-API status and device, and channel webhooks, on an instance outside the choice, respond `404`, with the same body as a channel of another workspace;
- `GET /channels` lists only the chosen instances, and `total` counts only them;
- with an empty choice, every channel route responds `404` and `GET /channels` comes back empty, with `total` 0;
- a connection with a choice does not read the global webhook or the account default (`GET /webhooks` and `GET /default-instance-webhooks`, and the read by id): the response is `403` with `{"error":"forbidden"}`.

A connection made before the instance choice keeps reaching the whole workspace until it is authorized again. WhatsApp Business accounts, templates and flows follow only the token scopes. A change in the choice takes effect within 5 seconds.

## Summary

|---|---|---|---|
