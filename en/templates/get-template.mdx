## Overview

Returns one template from the WABA by ID, with the same fields as each item in [List templates](/en/templates/list-templates).

The template comes from the platform snapshot, not straight from Meta. A template that is not in the snapshot returns `404`, even if it exists on Meta:

```json
{ "error": "Resource not found" }
```

The same `404` applies to a WABA that does not belong to your account.

<Warning>
  If the template returns `404`, run [Sync templates](/en/templates/sync-templates) and fetch it again.
</Warning>

<Note>
  The `templateId` is obtained from the [List templates](/en/templates/list-templates) endpoint.
</Note>
