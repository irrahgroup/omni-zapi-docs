## Overview

Sends a message with a list of options grouped in sections. The customer taps the button, opens the list and picks a row.

The `content.type` field is `INTERACTIVE_LIST`.

It is the format for when options do not fit in buttons: menu, service catalog, schedules, branches. For up to 3 options, prefer [quick reply buttons](/en/messages/send-interactive-button).

## Rules

Limits published by Meta for the list. The API passes the list on as received, and Meta refuses what goes over the limit.

| Rule | Limit |
|---|---|
| Sections | 10 |
| Rows | **10 across all sections** |
| Button text | 20 characters |
| Row title | 24 characters |
| Row description | 72 characters |
| Row `id` | unique within the message |

The row limit is **in total**, not per section.
