## Overview

Replaces the text of a text message your channel already sent. The recipient sees the new text in place of the old one, with the app's edited mark. No new message is sent.

The `messageId` in the path is the one the send returned. The `contents[].identifier` received in the webhook is also accepted. Recipient and sender are not asked for: those of the original message apply. Only text can be edited: the caption of an image, video or document gets `422` `MESSAGE_NOT_EDITABLE`.

<Note>
  The `200` confirms the edit was accepted and forwarded to the channel, not that the contact's app already shows the new text. If the channel refuses later, for example if the contact blocked the bot on Telegram or the message was deleted, the contact's text does not change and the API sends no notice of that refusal.
</Note>

## Errors

| Status | When |
|---|---|
| 400 | missing or empty body, `content.type` other than `TEXT`, or empty `content.body.message` |
| 404 | the `messageId` does not exist or is not from this channel |
| 422 `EDIT_NOT_SUPPORTED` | the channel does not allow editing |
| 422 `CHANNEL_DISCONNECTED` | the channel is disconnected |
| 422 `MESSAGE_NOT_EDITABLE` | the message is not text (including a media caption), was not sent by your channel, was not accepted by the channel yet or failed to send |
| 422 `EDIT_WINDOW_EXPIRED` | the period in which the channel accepts editing has passed |

Handle refusals by `subCode`. The `message` text may change.
