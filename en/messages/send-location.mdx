## Overview

Sends a location message to a contact. The `content.type` field must be `LOCATION` and the coordinates are provided in the `attachments` array using `latitude` and `longitude`.

The `name` and `address` fields are optional and allow displaying the place name and address directly in the message.

Send `latitude` and `longitude` as text, like the example: `"-23.0696347"`.

<Warning>
  The API does not validate the `latitude` and `longitude` fields. Requests without these values will be accepted, but the message will not display the location correctly on WhatsApp. Always provide both fields.
</Warning>

<Note>
  The `POST /v1/channels/{channelId}/send-location` route takes the same body as this page and gives the same response. On it, `content.type` is optional and, if you send it, it must be `LOCATION`. With any other value, the API responds `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be LOCATION on /send-location; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, and the message is not sent. See [Routes by type](/en/messages/introduction#routes-by-type).
</Note>
