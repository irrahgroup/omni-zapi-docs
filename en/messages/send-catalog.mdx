## Overview

Sends a message that opens the catalog connected to your account in Commerce Manager.

The `content.type` field will be `CATALOG`.

<ChannelSupport type="CATALOG" lang="en" />

## Request body

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "CATALOG",
    "message": "New arrivals in the store. Tap to see the full catalog.",
    "footer": "Prices valid while stock lasts",
    "thumbnailProductRetailerId": "SKU-1042"
  }
}
```

## Rules

| Rule | Value |
|---|---|
| Message | required, up to 1024 characters |
| Footer | optional, up to 60 characters |
| Cover product | optional; without it Meta uses the first item in the account |
| Catalog | must be connected in Commerce Manager |
