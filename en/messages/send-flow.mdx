## Overview

Sends a WhatsApp flow, an already published [Flow](/en/flows/introduction), straight into the conversation,
**with no template and no approval**. The customer taps the button and the flow opens inside WhatsApp. The
`content.type` field must be `INTERACTIVE_FLOW`.

## Fields

| Field | Rule |
|---|---|
| `body.message` | Required. Message text, above the button |
| `header.message` | Optional. Text title |
| `footer.message` | Optional. Footer |
| `action.name` | Required. Always `flow` |
| `action.version` | Required. Flow message version at Meta: `3` |
| `action.id` | Required. The `id` of a published flow in the same account as the channel, as returned by [List flows](/en/flows/list-flows) |
| `action.cta` | Required. Button text, up to 30 characters |
| `action.mode` | Optional. Without it, `published` applies |

There is no way to choose the opening screen, send data to it or send a session token.

<Warning>
  The answer the customer fills in does not reach your webhook with the flow fields yet.
</Warning>

<Note>
  If the channel is disconnected, the API refuses the send with `422` and `subCode` `CHANNEL_DISCONNECTED`, and the message is not sent. See [Send errors](/en/messages/introduction#send-errors).
</Note>
