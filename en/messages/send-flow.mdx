## Overview

Sends a WhatsApp form, an already created [Flow](/en/flows/introduction), straight into the conversation, **with no template**.

The `content.type` field is `INTERACTIVE_FLOW`.

## Rules

The API passes `action.name`, `action.version`, `action.cta` and `action.mode` on to Meta as received, with no default value.
