<Warning>
  **Being implemented.** Only **one contact per message** works today: `attachments` accepts a list, but nothing from the second item on is sent.

  We also carry only `name` and `phones`. [Meta accepts](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/contacts-messages) up to **257 contacts** in one send, and on each one also email, address, organization, birthday and website.

  We are extending the endpoint. Until then, send one contact per request.
</Warning>

## Overview

Sends a contact to a recipient. The `content.type` field must be `CONTACT`. You can send multiple phone numbers in the `phones` array.

<ChannelSupport type="CONTACT" lang="en" />

<Note>
  Details of the Meta Cloud API rule in [conversation window](/en/conversation-window). See [what each channel accepts](/en/channels/message-support) for every channel.
</Note>

<Note>
  If the channel is disconnected, the API refuses the send with `422` and `subCode` `CHANNEL_DISCONNECTED`, and the message is not sent. See [Send errors](/en/messages/introduction#send-errors).
</Note>

<Note>
  The `POST /v1/channels/{channelId}/send-contact` route takes the same body as this page and gives the same response. On it, `content.type` is optional and, if you send it, it must be `CONTACT`. With any other value, the API responds `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be CONTACT on /send-contact; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, and the message is not sent. See [Routes by type](/en/messages/introduction#routes-by-type).
</Note>
