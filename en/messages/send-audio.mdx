## Overview

Sends an audio message to a contact. The `content.type` field must be `AUDIO` and the audio is sent via URL in the `attachments` array.

<ChannelSupport type="AUDIO" lang="en" />

<Note>
  Details of the Meta Cloud API rule in [conversation window](/en/conversation-window). See [what each channel accepts](/en/channels/message-support) for every channel.
</Note>

<Note>
  If the channel is disconnected, the API refuses the send with `422` and `subCode` `CHANNEL_DISCONNECTED`, and the message is not sent. See [Send errors](/en/messages/introduction#send-errors).
</Note>

<Note>
  The `POST /v1/channels/{channelId}/send-audio` route takes the same body as this page and gives the same response. On it, `content.type` is optional and, if you send it, it must be `AUDIO`. With any other value, the API responds `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be AUDIO on /send-audio; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, and the message is not sent. See [Routes by type](/en/messages/introduction#routes-by-type).
</Note>
