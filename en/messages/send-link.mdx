## Overview

Sends a text with a link, shown with a preview or as a card, depending on the channel. The `content.type`
field must be `LINK`.

For the same body to work on every channel, fill `message` with the link and also `url` and `title`.
<Note>
  Details of the Meta Cloud API rule in [conversation window](/en/conversation-window). See [what each channel accepts](/en/channels/message-support) for every channel.
</Note>
<Note>
  If the channel is disconnected, the API refuses the send with `422` and `subCode` `CHANNEL_DISCONNECTED`, and the message is not sent. See [Send errors](/en/messages/introduction#send-errors).
</Note>
