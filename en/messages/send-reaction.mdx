## Overview

Applies an emoji to a message already in the conversation, sent by you or received from the customer. The
`content.type` field must be `REACTION`.

| Field | What goes in it |
|---|---|
| `body.id` | The `messageId` of the target message: the one the API returned when sending, or the `message._id` that came in the [webhook](/en/webhooks/payloads) of the received message |
| `body.message` | The emoji, a single one |

## Meta Cloud API rules

| Rule | Value |
|---|---|
| Age of the target message | less than **30 days** |
| Emoji | a single one, as a character or a unicode sequence |
| Reacting to a reaction | not accepted |
| Deleted message | not accepted |

<Warning>
  `body.id` is required. Without it, the API accepts the call with `200`, but the reaction is not sent.
</Warning>

<Note>
  If the channel is disconnected, the API refuses the send with `422` and `subCode` `CHANNEL_DISCONNECTED`, and the message is not sent. See [Send errors](/en/messages/introduction#send-errors).
</Note>
