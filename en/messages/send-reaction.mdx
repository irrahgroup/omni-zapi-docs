## Overview

Applies an emoji to a message already in the conversation. To remove it, send the same reaction with an
empty emoji.

The `content.type` field will be `REACTION`.

<ChannelSupport type="REACTION" lang="en" />

## Request body

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "REACTION",
    "messageId": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNBMDI...",
    "emoji": "👍"
  }
}
```

To remove it, send `"emoji": ""`.

## Rules

| Rule | Value |
|---|---|
| Age of the target message | less than **30 days** |
| Emoji | a single one, as a character or a unicode sequence |
| Reacting to a reaction | not accepted |
| Deleted message | not accepted |

<Note>
  A reaction only generates a **sent** webhook. There is no delivery or read confirmation. An invalid target
  comes back with code `131009`.
</Note>
