## Overview

Paginated list of the number's contacts.

<Note>
  Pagination uses an opaque cursor: send the `nextCursor` back exactly as received for the next page. `pageSize` is 20 by default, with no maximum. `nextCursor` is `null` only when the page has fewer items than `pageSize`; if the last page has exactly `pageSize` items, the next page comes back empty.
</Note>
