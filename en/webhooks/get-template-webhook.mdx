## Overview

Returns the data of a specific template webhook for the tenant. As with the list endpoint, authentication credentials and the `secret` are **not returned** for security reasons.

<Note>
  <EnterpriseText lang="en" />
</Note>

<Note>
  The `webhookId` is obtained from the [Create template webhook](/en/webhooks/create-template-webhook) or [List template webhooks](/en/webhooks/list-template-webhooks) endpoint.
</Note>
