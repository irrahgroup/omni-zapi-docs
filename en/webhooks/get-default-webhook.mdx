## Overview

Returns the data of a default webhook of the workspace. As in the list, authentication credentials and the `secret` are **not returned**.

An id from another workspace, of a channel webhook or of a template webhook gets `404`, the same response as an id that does not exist.

<Note>
  The `webhookId` comes from the [Create default webhook](/en/webhooks/create-default-webhook) or [List default webhooks](/en/webhooks/list-default-webhooks) response.
</Note>
