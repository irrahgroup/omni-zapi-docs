## Overview

Creates a global webhook. It does not depend on an instance (the `instanceId` is stored as `null` automatically) and receives only account events.

The `events` field accepts **only** the 9 account events: `UPDATE_TEMPLATE_STATUS`, `UPDATE_TEMPLATE_CATEGORY`, the five billing events (`BILLING_PAYMENT_FAILED`, `BILLING_PAYMENT_RECOVERED`, `BILLING_SUBSCRIPTION_CANCELED`, `BILLING_INSTANCE_SUSPENDED`, `BILLING_INSTANCE_RELEASED`), `ACCOUNT_RESTRICTION` and `CHANNEL_DISCONNECTED`. What each one means is in [Accepted events](/en/webhooks/template-webhooks#accepted-events). A channel event results in `422`.

<Note>
  The body, origins and reason codes of `CHANNEL_DISCONNECTED` are in [Channel disconnection notice](/en/webhooks/channel-disconnected).
</Note>

### Delivery format: use `DEFAULT`

The global webhook is delivered in the `DEFAULT` format. Send `payloadFormat` `DEFAULT` or omit the field.

| Case | Response |
|---|---|
| `events` with `ACCOUNT_RESTRICTION` and `payloadFormat` `Z_API` or `CHATWOOT` | `422` with `{"error": "ACCOUNT_RESTRICTION only supports DEFAULT payload format"}` |

### HMAC signing

If `signing: true`, the `secret` field is generated and returned **only in this response**. Store it securely — it will not be shown again.

The signature arrives in the `x-webhook-signature` header and is computed over a canonical string of five fields — not over the body alone. See [HMAC signing](/en/webhooks/signature).

### Validation

The request is refused with `400`, and nothing is saved, in these cases:

| Case | Response |
|---|---|
| `url` missing or blank | `{"error": "URL is required"}` |
| `url` in the wrong format, or with a host that does not resolve only to public addresses | see [Webhook URL](/en/webhooks/introduction#webhook-url) |
| `events` missing or empty | `{"error": "At least one event is required"}` |
| An `events` item that is null, blank, or a name that does not exist | `{"error": "events contains an unknown or empty event name"}` |
| `auth.type` `CUSTOM_HEADER` without `auth.headerName` | `{"error": "Header name is required for CUSTOM_HEADER auth type"}` |
| Authentication other than `NONE` without the credential for its type | `{"error": "Credentials are required when auth type is not NONE"}` |

Event names are accepted in any letter case. The invalid-name response does not echo the value you sent.

<Note>
  After creation, routing may take up to ~5 min to reflect (cache TTL).
</Note>
