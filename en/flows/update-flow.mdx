## Concepts

Updates an existing flow. Every field is optional — only the ones you send change.

<Warning>
  A `PUBLISHED` flow **does not accept** `flow_json` changes. To change the screens of an already published flow, create a new one and deprecate the old one with [Deprecate flow](/en/flows/deprecate-flow).
</Warning>
