## Overview

New-API group routes, under `/v1/channels/{channelId}/groups`, in the Omni format (not a Z-API copy). Phase 1 delivers **read only**, **on the WhatsApp Web channel** (`Z_API_WHATSAPP`): capabilities, list, get, invite link, and preview by link.

<Note>
  On a Meta channel (`META_WHATSAPP`), these routes are **not available in this API yet** and respond `422`: Meta is not wired here yet. Groups on Meta already work through the [compatible Z-API route](/en/z-api/limitations). The [capabilities](/en/groups/capabilities) route responds `200` with an empty `operations`.
</Note>

<Note>
  Writes (create group, rename, participants) come in phase 2.
</Note>

Authentication is the [Secret Key](/en/authentication). Only the `/v1/channels/{channelId}/...` path is served.

## Channel errors

On the list, get, invite link and preview routes, the API relays the request to the channel. Beyond the errors of each route, they may respond:

- **Channel refusal (`4xx`)**: the same status the channel gave, with `{"error": "provider_error", "message": "<channel text>"}`. The `message` may be missing.
- **`429`**: the same body, with the `Retry-After` header when the channel sends the wait in seconds. Wait that long before trying again.
- **`504`** `{"error": "integration_timeout", "message": "The operation took too long to complete. Try again in a few moments."}`: the channel ran out of time to answer. The route only reads data, so you can repeat the call.
- **`502`** `{"error": "integration_unavailable", ...}`: the connection to the channel failed, the channel answered `401`, `403`, `405` or `5xx`, or it gave an answer outside the expected format.
- **`502`** `{"error": "provider_response_too_large", "message": "The channel answer is too large. Use a smaller pageSize."}`: the channel answer went over the accepted size. Ask for a smaller page.
