## Overview

Paginated list of the number's groups.

<Note>
  Pagination uses an opaque cursor: send the `nextCursor` back as received for the next page. `pageSize` is 20 by default, with no maximum (a positive integer up to 9 digits). `nextCursor` is null only when the page has fewer items than `pageSize` — a last page with exactly `pageSize` items is followed by an empty page. The groups cursor (`g1:`) does not work for contacts.
</Note>
