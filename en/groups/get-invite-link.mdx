## Overview

The group's invite link.

<Note>
  The **channel** must be a group admin; otherwise, `422` `provider_error` with the message `The channel is not an admin of this group, so WhatsApp does not return its invite link. Make the channel an admin of the group, or ask a group admin for the link.`
</Note>
