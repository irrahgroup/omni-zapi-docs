## Conceituação

Aplica um emoji a uma mensagem que já está na conversa, enviada por você ou recebida do cliente. O campo
`content.type` deve ser `REACTION`.

| Campo | O que vai nele |
|---|---|
| `body.id` | O `messageId` da mensagem alvo: o que a API devolveu no envio, ou o `message._id` que chegou no [webhook](/webhooks/payloads) da mensagem recebida |
| `body.message` | O emoji, um só |

## Regras da Meta Cloud API

| Regra | Valor |
|---|---|
| Idade da mensagem alvo | menos de **30 dias** |
| Emoji | um só, como caractere ou sequência unicode |
| Reagir a uma reação | não é aceito |
| Mensagem apagada | não é aceita |

<Warning>
  O `body.id` é obrigatório. Sem ele, a API aceita a chamada com `200`, mas a reação não é enviada.
</Warning>

<Note>
  Com o canal desconectado, a API recusa o envio com `422` e `subCode` `CHANNEL_DISCONNECTED`, e a mensagem não é enviada. Veja [Erros no envio](/messages/introduction#erros-no-envio).
</Note>
