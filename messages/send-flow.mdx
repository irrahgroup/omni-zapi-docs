## Conceituação

Envia um formulário do WhatsApp, um [Flow](/flows/introduction) já publicado, direto na conversa, **sem
template e sem aprovação**. O cliente toca no botão e o formulário abre no próprio WhatsApp. O campo
`content.type` deve ser `INTERACTIVE_FLOW`.

## Campos

| Campo | Regra |
|---|---|
| `body.message` | Obrigatório. Texto da mensagem, acima do botão |
| `header.message` | Opcional. Título em texto |
| `footer.message` | Opcional. Rodapé |
| `action.name` | Obrigatório. Sempre `flow` |
| `action.version` | Obrigatório. Versão da mensagem de Flow na Meta: `3` |
| `action.id` | Obrigatório. O `id` de um formulário publicado na mesma conta do canal, como vem em [Listar flows](/flows/list-flows) |
| `action.cta` | Obrigatório. Texto do botão, até 30 caracteres |
| `action.mode` | Opcional. Sem ele, vale `published` |

Não há como escolher a tela de abertura, mandar dados para ela nem enviar um token de sessão.

<Warning>
  A resposta que o cliente preenche ainda não chega ao seu webhook com os campos do formulário.
</Warning>

<Note>
  Com o canal desconectado, a API recusa o envio com `422` e `subCode` `CHANNEL_DISCONNECTED`, e a mensagem não é enviada. Veja [Erros no envio](/messages/introduction#erros-no-envio).
</Note>
