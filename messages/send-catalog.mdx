## Conceituação

Manda uma mensagem que abre o catálogo conectado à sua conta no Commerce Manager.

O campo `content.type` será `CATALOG`.

<WindowRule lang="pt" template="de catálogo" href="/templates/models/catalog" />

<ChannelSupport type="CATALOG" lang="pt" />

## Corpo da requisição

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "CATALOG",
    "message": "Chegaram novidades na loja. Toque para ver o catálogo completo.",
    "footer": "Preços válidos enquanto durar o estoque",
    "thumbnailProductRetailerId": "SKU-1042"
  }
}
```

## Regras

| Regra | Valor |
|---|---|
| Mensagem | obrigatória, até 1024 caracteres |
| Rodapé | opcional, até 60 caracteres |
| Produto da capa | opcional; sem ele a Meta usa o primeiro item da conta |
| Catálogo | precisa estar conectado no Commerce Manager |
