## Conceituação

Troca o texto de uma mensagem de texto que o seu canal já enviou. O destinatário vê o texto novo no lugar do antigo, com a marca de editada do aplicativo. Nenhuma mensagem nova é enviada.

O `messageId` do path é o que o envio devolveu. O `contents[].identifier` recebido no webhook também é aceito. Destinatário e remetente não são pedidos: valem os da mensagem original. Só texto pode ser editado: a legenda de imagem, vídeo ou documento recebe `422` `MESSAGE_NOT_EDITABLE`.

<Note>
  O `200` confirma que a edição foi aceita e encaminhada ao canal, não que o aplicativo do contato já mostra o texto novo. Se o canal recusar depois, por exemplo se o contato bloqueou o bot no Telegram ou a mensagem foi apagada, o texto do contato não muda e a API não envia aviso dessa recusa.
</Note>

## Erros

| Status | Quando |
|---|---|
| 400 | corpo ausente ou vazio, `content.type` diferente de `TEXT` ou `content.body.message` vazio |
| 404 | o `messageId` não existe ou não é deste canal |
| 422 `EDIT_NOT_SUPPORTED` | o canal não permite edição |
| 422 `CHANNEL_DISCONNECTED` | o canal está desconectado |
| 422 `MESSAGE_NOT_EDITABLE` | a mensagem não é texto (inclusive legenda de mídia), não foi enviada pelo seu canal, ainda não foi aceita pelo canal ou falhou no envio |
| 422 `EDIT_WINDOW_EXPIRED` | passou o prazo em que o canal aceita edição |

Trate as recusas pelo `subCode`. O texto de `message` pode mudar.
