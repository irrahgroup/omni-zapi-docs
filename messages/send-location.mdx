<Warning>
  **Em implementação.** O envio de localização ainda não chega ao destinatário.

  Com `latitude` e `longitude` como texto — a forma do exemplo abaixo, e a que a [Meta documenta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/location-messages) — a API responde `json: cannot unmarshal string into Go struct field SendMessageInput.latitude of type float64`. Com número, a requisição é aceita, mas a mensagem não é entregue.

  A correção está em andamento. Enquanto isso, não há caminho que funcione neste endpoint.
</Warning>

## Conceituação

Envia uma mensagem de localização para um contato. O campo `content.type` deve ser `LOCATION` e as coordenadas são informadas no array `attachments` com `latitude` e `longitude`.

Os campos `name` e `address` são opcionais e permitem exibir o nome e o endereço do local diretamente na mensagem.

<Warning>
  A API não valida os campos `latitude` e `longitude`. Requisições sem esses valores serão aceitas, mas a mensagem não exibirá a localização corretamente no WhatsApp. Sempre informe ambos os campos.
</Warning>
