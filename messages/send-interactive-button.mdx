## Conceituação

Envia uma mensagem de texto com botões de resposta rápida. O campo `content.type` deve ser `INTERACTIVE_BUTTON`. O destinatário pode escolher entre as opções apresentadas.

Opcionalmente, você pode incluir uma **imagem** ou **vídeo** junto à mensagem usando os campos `thumbnail` e `mimeType` dentro do `body`.

<ChannelSupport type="INTERACTIVE_BUTTON" lang="pt" />

<Note>
  Detalhes da regra da Meta Cloud API em [janela de conversa](/conversation-window). Veja [o que cada canal aceita](/channels/message-support) para todos os canais.
</Note>

<Note>
  Com o canal desconectado, a API recusa o envio com `422` e `subCode` `CHANNEL_DISCONNECTED`, e a mensagem não é enviada. Veja [Erros no envio](/messages/introduction#erros-no-envio).
</Note>

<Note>
  A rota `POST /v1/channels/{channelId}/send-button-list` aceita o mesmo corpo desta página e dá a mesma resposta. Nela, `content.type` é opcional e, se vier, tem de ser `INTERACTIVE_BUTTON`. Com outro valor, a API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be INTERACTIVE_BUTTON on /send-button-list; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, e a mensagem não é enviada. Veja [Rotas por tipo](/messages/introduction#rotas-por-tipo).
</Note>
