## Conceituação

Envia uma mensagem com vídeo para um contato. O campo `content.type` deve ser `VIDEO` e o vídeo é enviado via URL no array `attachments`.

Opcionalmente, você pode incluir uma `caption` (legenda) junto ao vídeo.

<ChannelSupport type="VIDEO" lang="pt" />

<Note>
  Detalhes da regra da Meta Cloud API em [janela de conversa](/conversation-window). Veja [o que cada canal aceita](/channels/message-support) para todos os canais.
</Note>

<Note>
  Com o canal desconectado, a API recusa o envio com `422` e `subCode` `CHANNEL_DISCONNECTED`, e a mensagem não é enviada. Veja [Erros no envio](/messages/introduction#erros-no-envio).
</Note>

<Note>
  A rota `POST /v1/channels/{channelId}/send-video` aceita o mesmo corpo desta página e dá a mesma resposta. Nela, `content.type` é opcional e, se vier, tem de ser `VIDEO`. Com outro valor, a API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be VIDEO on /send-video; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, e a mensagem não é enviada. Veja [Rotas por tipo](/messages/introduction#rotas-por-tipo).
</Note>
