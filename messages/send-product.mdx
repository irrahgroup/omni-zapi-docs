## Conceituação

Envia um único produto do catálogo. A foto, o nome e o preço vêm do Commerce Manager.

O campo `content.type` será `PRODUCT`.

<WindowRule lang="pt" template="de produto único" href="/templates/models/spm" />

<ChannelSupport type="PRODUCT" lang="pt" />

## Corpo da requisição

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "PRODUCT",
    "message": "Este é o produto que você perguntou.",
    "footer": "Estoque limitado",
    "catalogId": "1234567890",
    "productRetailerId": "SKU-1042"
  }
}
```

## Regras

| Regra | Valor |
|---|---|
| `catalogId` e `productRetailerId` | os dois obrigatórios |
| Mensagem e rodapé | opcionais |
| SKU inexistente | a Meta recusa e não entrega a mensagem |
