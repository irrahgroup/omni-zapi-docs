<Warning>
  **Em implementação.** Todos os contatos do `attachments` são enviados, e cada canal entrega de um jeito:

  - **WhatsApp Oficial e WhatsApp Web:** todos os contatos chegam numa mensagem só.
  - **Telegram:** cada telefone de cada contato vira uma mensagem.
  - **Instagram:** a API recusa o envio na hora, com `422`.
  - **Messenger:** o canal não tem cartão de contato. A API responde `200`, mas a mensagem não chega.

  De cada contato, só levamos `name` e `phones`. A [Meta aceita](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/contacts-messages) também e-mail, endereço, organização, aniversário e site. Para mandar vários contatos, veja também [Enviar vários contatos](/messages/send-contacts).
</Warning>

## Conceituação

Envia um contato para um destinatário. O campo `content.type` deve ser `CONTACT`. Você pode enviar múltiplos telefones no array `phones`.

<ChannelSupport type="CONTACT" lang="pt" />

<Note>
  Detalhes da regra da Meta Cloud API em [janela de conversa](/conversation-window). Veja [o que cada canal aceita](/channels/message-support) para todos os canais.
</Note>

<Note>
  Com o canal desconectado, a API recusa o envio com `422` e `subCode` `CHANNEL_DISCONNECTED`, e a mensagem não é enviada. Veja [Erros no envio](/messages/introduction#erros-no-envio).
</Note>

<Note>
  A rota `POST /v1/channels/{channelId}/send-contact` aceita o mesmo corpo desta página e dá a mesma resposta. Nela, `content.type` é opcional e, se vier, tem de ser `CONTACT`. Com outro valor, a API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be CONTACT on /send-contact; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, e a mensagem não é enviada. Veja [Rotas por tipo](/messages/introduction#rotas-por-tipo).
</Note>
