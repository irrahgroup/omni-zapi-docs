## Conceituação

Envia um arquivo para o contato. O campo `content.type` é `DOCUMENT`.

O nome que o cliente vê é montado com `name` e `extension`: `"name": "nota-fiscal"` com `"extension": "pdf"`
chega como `nota-fiscal.pdf`, com o ícone de PDF.

## Regras

O campo `content.attachments` é obrigatório: sem ele, a API responde `400` com `VALIDATION_ERROR`. Sem `name`, o arquivo chega sem nome.

| Regra | Valor |
|---|---|
| Tamanho | até 100 MB |
| Tipos | PDF, Word, Excel, PowerPoint, texto |
| Legenda | até 1024 caracteres |

## Quando o canal recusa o arquivo

A API responde `200` com o `messageId` assim que aceita o pedido. Se depois o canal recusar o arquivo, por
exemplo um Base64 no Telegram ou uma planilha no Instagram, a mensagem não chega, e a falha vem no
webhook de status da mensagem (`MESSAGE_STATUS`). Veja [webhooks de canal](/webhooks/channel-webhooks).
