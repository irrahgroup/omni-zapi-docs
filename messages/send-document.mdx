## Conceituação

Envia um arquivo para o contato. O WhatsApp mostra o ícone conforme a extensão e o nome que você informar.

O campo `content.type` será `DOCUMENT`.

## Corpo da requisição

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "DOCUMENT",
    "attachments": [
      {
        "url": "https://sualoja.com/nota-fiscal.pdf",
        "fileName": "nota-fiscal.pdf",
        "caption": "Segue a sua nota fiscal"
      }
    ]
  }
}
```

## Regras

| Regra | Valor |
|---|---|
| Tamanho | até 100 MB |
| Tipos | PDF, Word, Excel, PowerPoint, texto |
| Legenda | até 1024 caracteres |
| `fileName` | **com extensão** — é ela que define o ícone que o cliente vê |

<Warning>
  O `fileName` vai com a extensão, como `nota-fiscal.pdf`. Na camada de compatibilidade Z-API existe hoje um
  defeito conhecido nesse campo: com extensão o arquivo chega como `nota-fiscal.pdf.pdf`, e sem extensão
  chega como `nota-fiscal.null`.
</Warning>
