## Conceituação

Manda uma mensagem com o botão **Enviar localização**. O cliente toca e o WhatsApp devolve o ponto dele
para o seu webhook.

É o contrário de [enviar localização](/messages/send-location): aqui quem manda o ponto é o cliente.

O campo `content.type` será `LOCATION_REQUEST`.

## Corpo da requisição

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "LOCATION_REQUEST",
    "message": "Para calcular o frete, toque abaixo e envie sua localização."
  }
}
```

## Regras

| Regra | Valor |
|---|---|
| Texto | até 1024 caracteres |
| Rótulo do botão | fixo do WhatsApp, traduzido para o idioma do cliente |

A resposta chega como uma mensagem de localização comum, com latitude, longitude e, quando o cliente
permite, nome e endereço.
