## Como funciona

Cada cartão é um espaço reservado para um produto: imagem, nome e preço vêm do catálogo **no envio**, e você escolhe qual produto em cada disparo.

A assimetria que pega todo mundo: a Meta exige **exatamente 2 cartões na criação**, mas aceita **até 10 no envio**.

## Na criação e no envio

| Na criação | No envio |
|---|---|
| A mensagem acima dos cartões | Os produtos, até 10 |
| Exatamente 2 cartões vazios | A foto, o nome e o preço de cada um |

## Campos deste modelo

| Campo | Para que serve | Regra |
|---|---|---|
| `category` | Fixa | Sempre `MARKETING` |
| `BODY` | A mensagem acima dos cartões | Até 1024 caracteres |
| `CAROUSEL.cards` | Os cartões | **Exatamente 2** na criação |
| `HEADER` do cartão | O espaço do produto | `format: PRODUCT`, sem mais nada |
| `BUTTONS` do cartão | O botão do cartão | **Um único** botão `SPM`, com o rótulo fixo |

<Warning>
  O cartão de produto **não tem texto**. Mandar um corpo no cartão, ou um segundo botão, volta como `component of type BODY is required`, código `2388045`, que não descreve a causa.
</Warning>

## JSON completo

São dois JSON: um **cria** o template, e a Meta aprova uma vez. O outro **envia** a mensagem, e vai a cada disparo, com os valores daquele envio nas variáveis marcadas com chaves.

### 1. Criar o template

`POST /whatsapp/businesses/{wabaId}/templates` — ver em [Referência da API](/templates/create-template).

{/* payload:product_card_carousel */}
```json
{
  "name": "exemplo_product_card_carousel",
  "category": "MARKETING",
  "language": "pt_BR",
  "allow_category_change": true,
  "parameter_format": "NAMED",
  "components": [
    {
      "type": "BODY",
      "text": "Olá {{nome_do_cliente}}, o seu pedido {{numero_do_pedido}} foi confirmado e sai para entrega hoje.",
      "example": {
        "body_text_named_params": [
          {
            "param_name": "nome_do_cliente",
            "example": "Marina"
          },
          {
            "param_name": "numero_do_pedido",
            "example": "1042"
          }
        ]
      }
    },
    {
      "type": "CAROUSEL",
      "cards": [
        {
          "components": [
            {
              "type": "HEADER",
              "format": "PRODUCT"
            },
            {
              "type": "BUTTONS",
              "buttons": [
                {
                  "type": "SPM",
                  "text": "Ver"
                }
              ]
            }
          ]
        },
        {
          "components": [
            {
              "type": "HEADER",
              "format": "PRODUCT"
            },
            {
              "type": "BUTTONS",
              "buttons": [
                {
                  "type": "SPM",
                  "text": "Ver"
                }
              ]
            }
          ]
        }
      ]
    }
  ]
}
```

### 2. Enviar depois de aprovado

`POST /v1/channels/{channelId}/messages` — ver em [Enviar template](/messages/send-template).

{/* send:product_card_carousel */}
```json

  "recipient": {
    "identifier": "5511999999999"
  },
  "content": {

                {
```

## O que a Meta recusa aqui

- Número de cartões diferente de 2 na criação.
- Texto no cartão de produto.
- Dois botões no mesmo cartão.
- Rótulo diferente do exigido no botão `SPM`: `Ver` em template `pt_BR`, `View` nos outros.
