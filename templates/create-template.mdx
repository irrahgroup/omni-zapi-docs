## Conceituação

<Warning>
  Este endpoint é escopado por **WABA**, então hoje cobre só o **WhatsApp Oficial**.

  Instagram e Messenger também têm template pré-aprovado — o **Utility Template**, escopado por página. O suporte a eles no Omni Z-API está **em implementação**. Veja a [comparação dos três tipos de template](/templates/introduction).
</Warning>

Cria um novo template de mensagem e envia para aprovação da Meta. O template começa com status `PENDING` e é atualizado para `APPROVED` ou `REJECTED` após a revisão.

Use o endpoint de [Sincronizar templates](/templates/sync-templates) para forçar a atualização do status.

<Warning>
  O nome do template deve ser em `snake_case`, sem espaços ou caracteres especiais. Uma vez criado, o nome não pode ser alterado.
</Warning>

<Note>
  O `wabaId` é obtido através do endpoint de [Listar WABAs](/templates/list-businesses).
</Note>

## Modelos prontos

O seletor de exemplos da requisição acima tem **um payload por tipo de
template**: carrossel de mídia, cupom, oferta por tempo limitado, multi-produto,
detalhes do pedido e os demais. Escolha o modelo e copie o JSON.

Cada tipo aceita componentes diferentes, e é isso que [Tipos de template](/templates/types)
explica. O que a Meta recusa em cada campo está em [Validações](/templates/validation).

## Qual campo vale em qual componente

Cada item de `components` é um objeto identificado pelo `type`. A tabela diz
quais campos aquele tipo usa.

| `type` | Campos |
|---|---|
| `HEADER` | `format`, `text` (60), `example` |
| `BODY` | `text` (1024), `example`, `add_security_recommendation` |
| `FOOTER` | `text` (60), `code_expiration_minutes` |
| `BUTTONS` | `buttons` |
| `CAROUSEL` | `cards` |
| `LIMITED_TIME_OFFER` | `limited_time_offer` |
| `CALL_PERMISSION_REQUEST` | nenhum |

E nos botões, dentro de `buttons`:

| `type` | Campos |
|---|---|
| `QUICK_REPLY` | `text` (25) |
| `URL` | `text`, `url`, `example` |
| `PHONE_NUMBER` | `text`, `phone_number` |
| `COPY_CODE` | `example` (o código, até 20) |
| `OTP` | `otp_type`, `supported_apps`, `zero_tap_terms_accepted` |
| `FLOW` | `text`, `flow_id` ou `flow_name` ou `flow_json`, `flow_action`, `navigate_screen` |
| `CATALOG`, `MPM`, `SPM`, `PAYMENT_REQUEST`, `ORDER_DETAILS`, `VOICE_CALL` | nenhum: a Meta escreve o rótulo |
