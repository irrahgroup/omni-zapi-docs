O tipo define **quais campos existem** no template e o que a Meta cobra em cada um. Escolher o tipo é a primeira decisão, e ela não muda depois: para trocar, você cria outro template.

<Note>
  As pré-visualizações abaixo são aproximações de como o cliente vê no WhatsApp. O que aparece com `{{chaves}}` é variável, preenchida no envio.
</Note>

<Info>
  **O payload de cada tipo** está em [Criar template](/templates/create-template), no seletor de exemplos da requisição: um modelo pronto por tipo. As regras que a Meta cobra em cada campo estão em [Validações](/templates/validation).
</Info>

## Aprovação e envio: duas coisas diferentes

Vários tipos são **aprovados uma vez e alimentados no envio**. O template guarda a estrutura; os dados vão na hora de disparar.

| Aprovado na criação | Enviado a cada disparo |
|---|---|
| texto, botões, estrutura dos cartões | valores das variáveis |
| categoria e idioma | produtos, itens do pedido, mídia dos cartões |
| a amostra de mídia que a Meta revisa | a mídia real de cada envio |

Isso é o que permite usar **o mesmo template aprovado em campanhas diferentes**.

## Limites de texto

| Campo | Limite |
|---|---|
| Cabeçalho | 60 caracteres, no máximo **uma** variável |
| Mensagem | 1024 caracteres |
| Rodapé | 60 caracteres, **sem** variáveis |
| Texto de botão | 25 caracteres |
| Texto de cartão do carrossel | 160 caracteres |
| Texto de oferta | 16 caracteres |
| Código de cupom | 20 caracteres |
