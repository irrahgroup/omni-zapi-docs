## Conceituação

Desconecta o número de um canal `Z_API_WHATSAPP` (WhatsApp Web). A rota não tem corpo. Para ligar o canal de novo, leia o QR Code outra vez, como em [Conectar WhatsApp Web](/connect/whatsapp-web).

## Exemplo

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DO_CANAL/zapi/disconnect \
  -H "Authorization: Bearer SUA_SECRET_KEY"
```

## Resposta

`200` com `true`:

```json
true
```

## Erros

Os erros (`401`, `403`, `404`, `422` e `502`) são comuns às rotas de desconexão e estão em [Erros](/channels/disconnect#erros).
