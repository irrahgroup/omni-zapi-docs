## Conceituação

Os endpoints desta seção gerenciam o ciclo de vida dos canais do seu workspace: criar, consultar, conectar, desconectar, assinar e remover. O `id` que a criação devolve é o `channelId`, usado em todas as outras chamadas da API, como mensagens, templates e webhooks.

Para entender o que é um canal e o passo a passo para começar, veja a [Introdução aos canais](/channels/introduction). Para conectar cada tipo de canal, veja [Conectar um canal](/connect/introduction).

## Rotas

| Página | Rota | O que faz | Quem chama |
|---|---|---|---|
| [Criar canal](/channels/create-channel) | `POST /v1/channels` | Cria o canal e devolve o `channelId` | Secret Key ou token OAuth de app autorizado |
| [Listar canais](/channels/list-channels) | `GET /v1/channels` | Lista os canais do workspace, com filtro por `type` | Secret Key, role ENTERPRISE |
| [Consultar canal](/channels/get-channel) | `GET /v1/channels/{channelId}` | Devolve os dados do canal e os webhooks cadastrados nele | Secret Key, role ENTERPRISE |
| [Conectar canal](/channels/connect-channel) | `POST /v1/channels/{channelId}/connect` | Finaliza a conexão no backend, com os dados que o SDK devolveu | Secret Key |
| [Ativar canal Instagram](/channels/activate-instagram) | `POST /v1/channels/{channelId}/activate-instagram` | Finaliza a conexão do canal `META_INSTAGRAM` no backend | Secret Key |
| [Ativar canal Messenger](/channels/activate-messenger) | `POST /v1/channels/{channelId}/activate-messenger` | Finaliza a conexão do canal `META_MESSENGER` no backend | Secret Key |
| [Ativar canal Telegram](/channels/activate-telegram) | `POST /v1/channels/{channelId}/activate-telegram` | Finaliza a conexão do canal `BOT_TELEGRAM` no backend | Secret Key |
| [Consultar status do WhatsApp Web](/channels/get-whatsapp-web-status) | `GET /v1/channels/{channelId}/zapi/status` | Informa se o QR Code foi lido e se o número está conectado | Secret Key |
| [Consultar aparelho do WhatsApp Web](/channels/get-whatsapp-web-device) | `GET /v1/channels/{channelId}/zapi/device` | Informa o número e o aparelho vinculados ao canal | Secret Key |
| [Consultar origens do SDK](/channels/sdk-info) | `GET /instances/{channelId}/sdk-info` | Mostra os domínios liberados para o SDK de conexão | Public Key |
| [Desconectar canal Meta WhatsApp](/channels/disconnect-meta-whatsapp) | `PUT /v1/channels/{channelId}/disconnect` | Desconecta o canal e limpa os dados da conexão | Secret Key |
| [Desconectar canal Instagram](/channels/deactivate-instagram) | `POST /v1/channels/{channelId}/deactivate-instagram` | Desconecta o canal Instagram | Secret Key |
| [Desconectar canal Messenger](/channels/deactivate-messenger) | `POST /v1/channels/{channelId}/deactivate-messenger` | Desconecta o canal Messenger | Secret Key |
| [Desconectar canal Telegram](/channels/deactivate-telegram) | `POST /v1/channels/{channelId}/deactivate-telegram` | Desconecta o canal Telegram | Secret Key |
| [Desconectar canal WhatsApp Web](/channels/disconnect-whatsapp-web) | `POST /v1/channels/{channelId}/zapi/disconnect` | Desconecta o número do WhatsApp Web | Secret Key |
| [Assinar canal](/channels/subscribe-channel) | `GET /v1/channels/{channelId}/subscribe` | Adiciona o canal à assinatura depois do pagamento no painel | Secret Key, role ENTERPRISE |
| [Cancelar assinatura](/channels/cancel-subscription) | `DELETE /v1/channels/{channelId}/cancel` | Pede o cancelamento da assinatura do canal | Secret Key, role ENTERPRISE |
| [Remover canal](/channels/delete-channel) | `DELETE /v1/channels/{channelId}` | Exclui o canal | Secret Key, role ENTERPRISE |

A Secret Key é a do seu workspace, usada no backend. Veja [Autenticação](/authentication).

## Tipos de canal

Em [Criar canal](/channels/create-channel), o campo de tipo aceita `META_WHATSAPP`, `Z_API_WHATSAPP`, `META_INSTAGRAM`, `META_MESSENGER` e `BOT_TELEGRAM`. As páginas [Conectar canal](/channels/connect-channel) e [Desconectar canal](/channels/disconnect-meta-whatsapp) descrevem o fluxo do `META_WHATSAPP`.
