## Conceituação

Exclui um canal. Depois de excluído, o canal deixa de poder ser usado, e não é possível desfazer a exclusão pela API.

### Condições para exclusão

A exclusão só é permitida quando o canal está [desconectado](/channels/disconnect) e não possui assinatura ativa. Com o canal conectado, a API responde `422` com `{"error":{"type":"INSTANCE_STILL_CONNECTED", ...}}`; o código vem em `error.type`. A tabela abaixo descreve o comportamento por status:

| Status | Exclusão permitida | Observação |
|---|---|---|
| Trial | Sim | Nenhuma |
| Pendente | Sim | Se houver fatura aberta, ela será cancelada automaticamente |
| Pago | Não | O canal deve ser cancelado antes de ser excluído |
| Em processo de cancelamento | Não | O canal deve ser cancelado antes de ser excluído |
| Cancelado | Sim | Nenhuma |

<Warning>
  A exclusão não pode ser desfeita pela API. Para excluir um canal com assinatura ativa, primeiro cancele a assinatura via [Cancelar assinatura](/channels/cancel-subscription) e aguarde o status `CANCELED`.
</Warning>

### Erro `502`

Se a exclusão falhar no serviço interno, a API responde `502` com o corpo abaixo, sem detalhes internos. Tente novamente e, se o erro persistir, fale com o suporte.

```json
{
  "error": "integration_unavailable",
  "message": "The operation could not be completed right now. Try again in a few moments."
}
```

<Note>
  O `channelId` é obtido através do endpoint [Criar canal](/channels/create-channel).
</Note>
