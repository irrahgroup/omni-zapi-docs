## Conceituação

Desconecta um canal `BOT_TELEGRAM`. A rota não tem corpo e também marca o canal como desconectado. Para ligar o canal de novo, veja [Ativar canal](/channels/activate-channel).

## Exemplo

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DO_CANAL/deactivate-telegram \
  -H "Authorization: Bearer SUA_SECRET_KEY"
```

## Resposta

`200` com `true`:

```json
true
```

## Erros

Os erros (`401`, `403`, `404`, `422` e `502`) são comuns às rotas de desconexão e estão em [Erros](/channels/disconnect#erros).
