---
title: "Status e aparelho do WhatsApp Web"
description: "Consulte se um canal WhatsApp Web está conectado e qual aparelho está vinculado"
---

Duas rotas de leitura para canais `Z_API_WHATSAPP` (WhatsApp Web). As duas usam a Secret Key no header `Authorization: Bearer SUA_SECRET_KEY`. Chame sempre do backend. Veja [Autenticação](/authentication).

O fluxo do QR Code está em [Conectar WhatsApp Web](/connect/whatsapp-web).

## Status da conexão

`GET /v1/channels/{channelId}/zapi/status`

Use esta rota para saber se o QR Code foi lido e se o número está conectado.

```bash
curl https://api.omni.z-api.io/v1/channels/ID_DO_CANAL/zapi/status \
  -H "Authorization: Bearer SUA_SECRET_KEY"
```

Resposta `200`:

```json
{
  "connected": true,
  "session": true,
  "created": 1764064800000,
  "error": "",
  "smartphoneConnected": true
}
```

| Campo | Tipo | Descrição |
|---|---|---|
| `connected` | boolean | `true` quando o QR Code foi lido e o número está conectado |
| `session` | boolean | Se existe sessão do WhatsApp Web |
| `created` | number ou `null` | Momento de criação da sessão, quando houver |
| `error` | string | Texto do erro, quando houver |
| `smartphoneConnected` | boolean | Se o celular do número está conectado |

## Aparelho conectado

`GET /v1/channels/{channelId}/zapi/device`

Use esta rota para saber qual número e qual aparelho estão vinculados ao canal.

```bash
curl https://api.omni.z-api.io/v1/channels/ID_DO_CANAL/zapi/device \
  -H "Authorization: Bearer SUA_SECRET_KEY"
```

A resposta `200` traz estes campos:

| Campo | Descrição |
|---|---|
| `phone` | Número conectado |
| `imgUrl` | URL da foto do perfil |
| `name` | Nome do perfil |
| `device.sessionName` | Nome da sessão |
| `device.deviceModel` | Modelo do aparelho |
| `originalDevice` | Aparelho original |
| `sessionId` | ID da sessão |
| `isBusiness` | Se a conta é do WhatsApp Business |

## Erros

As duas rotas respondem com os mesmos erros:

| Status | Corpo | Quando acontece |
|---|---|---|
| `401` | `{"error": "Authorization invalid", "message": "..."}` | A Secret Key foi recusada. Veja os motivos em [Autenticação](/authentication) |
| `403` | `{"error": "ip_not_allowed", "message": "..."}` | O IP de origem está fora da lista. Veja [Restrição de IP](/security/ip-restriction) |
| `404` | `{"error": "Instance not found"}` | O canal não existe ou é de outro workspace |
| `422` | `{"error": { ... }}` | O provedor recusou a consulta. O campo `error` traz o envelope do provedor |
| `502` | `{"error": "integration_unavailable", "message": "..."}` | Um serviço interno está indisponível. Tente de novo em alguns instantes |

Para desconectar o número, veja [Desconectar canal](/channels/disconnect).
