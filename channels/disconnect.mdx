## Conceituação

Desconecta um canal **`META_WHATSAPP`** da API Oficial do WhatsApp e limpa todos os dados de conexão associados (WABA ID, phone ID, número conectado e coexistência).

Use este endpoint quando o usuário quiser desconectar intencionalmente o número — por exemplo, ao trocar de número ou encerrar o uso do canal.

Para Instagram, Messenger, Telegram e WhatsApp Web, veja [Outros tipos de canal](#outros-tipos-de-canal).

<Warning>
  Após a desconexão, o canal **não receberá mais mensagens**. Para voltar a funcionar, o canal precisará ser [reconectado](/channels/connect-channel).
</Warning>

## Outros tipos de canal

Os outros tipos de canal têm uma rota própria. Todas usam `POST`, não têm corpo e usam a Secret Key no header `Authorization: Bearer SUA_SECRET_KEY`.

| Tipo do canal | Rota |
|---|---|
| `META_INSTAGRAM` | `POST /v1/channels/{channelId}/deactivate-instagram` |
| `META_MESSENGER` | `POST /v1/channels/{channelId}/deactivate-messenger` |
| `BOT_TELEGRAM` | `POST /v1/channels/{channelId}/deactivate-telegram` |
| `Z_API_WHATSAPP` (WhatsApp Web) | `POST /v1/channels/{channelId}/zapi/disconnect` |

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DO_CANAL/deactivate-instagram \
  -H "Authorization: Bearer SUA_SECRET_KEY"
```

As quatro respondem `200` com `true`. As rotas `deactivate-*` também marcam o canal como desconectado. Para ligar de novo um canal Instagram, Messenger ou Telegram, veja [Ativar canal](/channels/activate-channel). Para o WhatsApp Web, leia o QR Code de novo, como em [Conectar WhatsApp Web](/connect/whatsapp-web).

| Status | Corpo | Quando acontece |
|---|---|---|
| `401` | `{"error": "Authorization invalid", "message": "..."}` | A Secret Key foi recusada. Veja os motivos em [Autenticação](/authentication) |
| `403` | `{"error": "ip_not_allowed", "message": "..."}` | O IP de origem está fora da lista. Veja [Restrição de IP](/security/ip-restriction) |
| `404` | `{"error": "Instance not found"}` | O canal não existe ou é de outro workspace |
| `422` | `{"error": { ... }}` | O provedor recusou a desconexão. O campo `error` traz o envelope do provedor |
| `502` | `{"error": "integration_unavailable", "message": "..."}` | Um serviço interno está indisponível. Tente de novo em alguns instantes |
