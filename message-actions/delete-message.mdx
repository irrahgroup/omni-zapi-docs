## Conceituação

Apaga a mensagem para todos.

<Note>
  A exclusão é **assíncrona**: o `200` confirma que o pedido foi aceito; o resultado chega depois. A resposta traz o `messageId` da **própria mensagem apagada** — o mesmo id do caminho.
</Note>
