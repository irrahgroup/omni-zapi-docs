## Conceituação

Retorna os dados de um webhook padrão do workspace. Assim como na listagem, as credenciais de autenticação e o `secret` **não são retornados**.

Um id de outro workspace, de um webhook de canal ou de um webhook de template recebe `404`, a mesma resposta de um id que não existe.

<Note>
  O `webhookId` é obtido no retorno do endpoint [Criar webhook padrão](/webhooks/create-default-webhook) ou [Listar webhooks padrão](/webhooks/list-default-webhooks).
</Note>
