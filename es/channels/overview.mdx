## No todo canal acepta todo

El cuerpo de la solicitud es el mismo en todos los canales, pero cada plataforma tiene sus límites:
Instagram no tiene mensaje de ubicación, Telegram no tiene botón de llamar, el catálogo de productos
solo existe donde hay catálogo. **El límite es de la plataforma, no de nuestra API.**

## Cómo identificamos el contacto

El campo `recipient.identifier` cambia de formato según el canal:

|  | Meta Cloud API | WhatsApp Web | Instagram | Messenger | Telegram |
|---|---|---|---|---|---|
| **Identificador** | teléfono con código de país | teléfono con código de país | usuario | página de Facebook | usuario del bot |
| **Ejemplo** | `5511999999999` | `5511999999999` | `@tu_tienda` | ID de la página | `@tu_bot` |
