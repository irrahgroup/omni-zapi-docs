## Conceptos

Elimina un canal. Una vez eliminado, el canal ya no se puede usar, y el borrado no se puede deshacer mediante la API.

<Warning>
  <EnterpriseText lang="es" />
</Warning>

### Condiciones para eliminar

Solo se permite eliminar el canal cuando está [desconectado](/es/channels/disconnect) y no tiene una suscripción activa. Si el canal sigue conectado, la API responde `422` con `INSTANCE_STILL_CONNECTED`. La siguiente tabla describe el comportamiento según el estado:

| Estado | ¿Se permite eliminar? | Observación |
|---|---|---|
| Prueba | Sí | — |
| Pendiente | Sí | Si hay una factura abierta, se cancelará automáticamente |
| Pagado | No | El canal debe cancelarse antes de eliminarlo |
| En proceso de cancelación | No | El canal debe cancelarse antes de eliminarlo |
| Cancelado | Sí | — |

<Warning>
  El borrado no se puede deshacer mediante la API. Para eliminar un canal con suscripción activa, primero cancela la suscripción con [Cancelar suscripción](/es/channels/cancel-subscription) y espera a que el estado sea `CANCELED`.
</Warning>

### Error `502`

Si el borrado falla en el servicio interno, la API responde `502` con el cuerpo siguiente, sin detalles internos. Inténtalo de nuevo y, si el error persiste, contacta con soporte.

```json
{ "error": "Hermitage deleteChannel failed" }
```

<Note>
  El `channelId` se obtiene a través del endpoint [Crear canal](/es/channels/create-channel).
</Note>
