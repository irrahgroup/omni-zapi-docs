## Conceptualización

Desconecta el número de un canal `Z_API_WHATSAPP` (WhatsApp Web). La ruta no lleva cuerpo. Para volver a encender el canal, escanea el código QR de nuevo, como en [Conectar WhatsApp Web](/es/connect/whatsapp-web).

## Ejemplo

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DEL_CANAL/zapi/disconnect \
  -H "Authorization: Bearer SU_SECRET_KEY"
```

## Respuesta

`200` con `true`:

```json
true
```

## Errores

Los errores (`401`, `403`, `404`, `422` y `502`) son comunes a las rutas de desconexión y están en [Errores](/es/channels/disconnect#errores).
