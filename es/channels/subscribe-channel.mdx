## Conceptos

Incluye el canal en la suscripción de la cuenta. Úsalo después de [Crear canal](/es/channels/create-channel): el canal nace en `TRIAL` por 2 días y, para mantenerlo, hay que suscribirlo.

### La respuesta tiene dos formas

**Con un pago pendiente**, la respuesta trae `checkoutId` y `url`. Envía al usuario a la `url` para completar el pago. Si informaste `redirectUrl` en la query, el checkout vuelve a esa dirección al final.

```json
{
  "checkoutId": "cs_a1B2c3D4e5F6",
  "url": "https://checkout.stripe.com/c/pay/cs_a1B2c3D4e5F6"
}
```

**Sin checkout**, la suscripción se actualiza al momento y la respuesta trae `type` `SUBSCRIPTION_UPDATED`. El cargo proporcional al resto del ciclo entra en la próxima factura.

```json
{
  "type": "SUBSCRIPTION_UPDATED",
  "message": "Canal activo. El cargo proporcional se incluirá en la próxima factura."
}
```

### Errores

| Estado | Cuerpo | Cuándo |
|---|---|---|
| `400` | `{"error":"Authorization invalid"}` | Secret Key ausente, mal formada o inexistente |
| `400` | `{"error":"203.0.113.10 not allowed"}` | IP fuera de la [lista de IPs](/es/security/ip-restriction) |
| `404` | `{"error":"Instance not found"}` | Canal inexistente o de otro workspace |
| `422` | `{"error":"Channel subscription requires ENTERPRISE role"}` | Cuenta sin el rol ENTERPRISE |
| `422` | `{"error":{"type":"CREDIT_LIMIT_EXCEEDED", ...}}` | Se alcanzó el límite de crédito de la cuenta |
| `422` | `{"error":{"type":"SUBSCRIPTION_TERMINATED", ...}}` | Suscripción finalizada; no se pueden añadir canales |
| `502` | `{"error":"integration_unavailable", ...}` | Falla de integración; vuelve a intentarlo en unos instantes |

<Note>
  El `channelId` se obtiene mediante el endpoint [Crear canal](/es/channels/create-channel) o [Listar canales](/es/channels/list-channels).
</Note>
