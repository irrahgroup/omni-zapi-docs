## Conceptos

Solicita la cancelación de la suscripción de un canal. La cancelación no es inmediata: el canal pasa al estado `CANCELLATION_PROCESS` y sigue activo hasta el final del periodo ya pagado. Transcurrido ese periodo, el estado cambia a `CANCELED`.

El parámetro de query `cancel=true` es obligatorio, como confirmación explícita de la cancelación.

El cuerpo es obligatorio: sin él, la API responde `400` con `{"error":"Required request body is missing"}`. Envía al menos `{}`. El campo `cancelReason` es opcional, pero se recomienda incluirlo con fines de auditoría.

Sin el parámetro `cancel`, la API responde `400` con `{"error":"Required parameter 'cancel' is missing"}`; con un valor que no es booleano, `{"error":"Invalid value for parameter 'cancel'"}`.

### Estados después de la cancelación

| Estado | Descripción |
|---|---|
| `CANCELLATION_PROCESS` | Cancelación solicitada; el canal sigue activo hasta el final del periodo |
| `CANCELED` | Canal cancelado y desactivado de forma efectiva |

<Warning>
  La cancelación no se puede deshacer mediante la API. Para reactivar el canal hay que iniciar una nueva suscripción con [Suscribir canal](/es/channels/subscribe-channel).
</Warning>

<Note>
  El `channelId` se obtiene a través del endpoint [Crear canal](/es/channels/create-channel).
</Note>
