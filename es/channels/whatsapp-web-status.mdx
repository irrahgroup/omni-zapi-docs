---
title: "Estado y dispositivo de WhatsApp Web"
description: "Consulta si un canal WhatsApp Web está conectado y qué dispositivo está vinculado"
---

Dos rutas de lectura para canales `Z_API_WHATSAPP` (WhatsApp Web). Las dos usan la Secret Key en el header `Authorization: Bearer SU_SECRET_KEY`. Llámalas siempre desde el backend. Consulta [Autenticación](/es/authentication).

El flujo del código QR está en [Conectar WhatsApp Web](/es/connect/whatsapp-web).

## Rutas

| Página | Ruta | Para qué sirve |
|---|---|---|
| [Consultar estado de WhatsApp Web](/es/channels/get-whatsapp-web-status) | `GET /v1/channels/{channelId}/zapi/status` | Saber si se leyó el código QR y si el número está conectado |
| [Consultar dispositivo de WhatsApp Web](/es/channels/get-whatsapp-web-device) | `GET /v1/channels/{channelId}/zapi/device` | Saber qué número y qué dispositivo están vinculados al canal |

## Errores

Las dos rutas responden con los mismos errores:

| Status | Cuerpo | Cuándo ocurre |
|---|---|---|
| `401` | `{"error": "Authorization invalid", "message": "..."}` | La Secret Key fue rechazada. Consulta los motivos en [Autenticación](/es/authentication) |
| `403` | `{"error": "ip_not_allowed", "message": "..."}` | La IP de origen está fuera de la lista. Consulta [Restricción de IP](/es/security/ip-restriction) |
| `404` | `{"error": "Instance not found"}` | El canal no existe o pertenece a otro workspace |
| `422` | `{"error": {"errors": [{"code": "413", ...}]}}` | El canal no es WhatsApp Web (`error.errors[0].code` `"413"`, `name` `IS_NOT_Z_API_WHATSAPP_CHANNEL`). El `status` dentro del cuerpo viene `400`, pero vale el `422` de la respuesta |
| `422` | `{"error": { ... }}` o `{"error": "..."}` | Otro caso: el proveedor rechazó la consulta. El campo `error` trae el envoltorio del proveedor o, sin envoltorio, un texto genérico |
| `502` | `{"error": "integration_unavailable", "message": "..."}` | Un servicio interno no está disponible. Inténtalo de nuevo en unos instantes |

Ejemplo del `422` cuando el canal no es WhatsApp Web:

```json
{
  "error": {
    "timestamp": "2026-10-22T14:00:00.123Z",
    "status": 400,
    "errors": [
      {
        "code": "413",
        "name": "IS_NOT_Z_API_WHATSAPP_CHANNEL",
        "message": "Not a Z-API WhatsApp channel",
        "description": "The channel is not of type Z_API_WHATSAPP"
      }
    ]
  }
}
```

Para desconectar el número, consulta [Desconectar canal](/es/channels/disconnect).
