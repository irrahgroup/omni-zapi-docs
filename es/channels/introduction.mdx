## ¿Qué es un canal?

En {projectName}, un **canal** representa la conexión con una cuenta de mensajes. El canal puede ser de WhatsApp (por la API Oficial de Meta o por WhatsApp Web), Instagram, Messenger o Telegram.

Cada canal está vinculado a una cuenta del tipo elegido: un número de WhatsApp, una cuenta profesional de Instagram, una página de Facebook o un bot de Telegram. Por ejemplo, al conectar el número `+55 11 99999-9999` por la API Oficial se crea un canal con un `channelId` único que se usa en todas las llamadas a la API.

El `channelId` es el identificador único del canal y se utiliza en todas las llamadas a la API para enviar [mensajes libres](/es/messages/introduction), [plantillas](/es/messages/send-template), webhooks, etc.

## Plataformas compatibles

| Plataforma | Tipo | Conexión |
|---|---|---|
| **WhatsApp** (API Oficial de Meta) | `META_WHATSAPP` | [Cloud API o Coexistencia](/es/whatsapp-official/connection/introduction) |
| **WhatsApp Web** | `Z_API_WHATSAPP` | Código QR |
| **Instagram** | `META_INSTAGRAM` | OAuth de Meta |
| **Messenger** | `META_MESSENGER` | OAuth de Meta |
| **Telegram** | `BOT_TELEGRAM` | Token del bot |

<Note>
  El `channelId` y los endpoints de [mensajes](/es/messages/introduction) y [webhooks](/es/webhooks/introduction) funcionan igual para todos los tipos. Lo que cambia es el flujo de conexión y, en el caso de Meta Cloud API, la [ventana de 24 horas](/es/conversation-window).
</Note>

## Flujo para empezar

<Steps>
  <Step title="Genera tus credenciales">
    Si aún no lo has hecho, genera tu **Public Key** y tu **Secret Key** en [Autenticación](/es/authentication).
  </Step>
  <Step title="Crea el canal">
    Crea un canal nuevo desde el [Panel](https://app.omni.z-api.io) o mediante la API con el endpoint [Crear canal](/es/channels/create-channel).
  </Step>
  <Step title="Conecta el canal">
    Conecta desde el panel o usa el [flujo de conexión con SDK + API](/es/connect/introduction). La ruta que finaliza la conexión depende del tipo de canal.
  </Step>
  <Step title="Activa la suscripción (cuentas ENTERPRISE)">
    Los partners y revendedores con rol ENTERPRISE deben activar la suscripción del canal mediante [Suscribir canal](/es/channels/subscribe-channel) antes de empezar a usarlo.
  </Step>
  <Step title="Envía mensajes">
    Con el canal conectado, usa el `channelId` para enviar [mensajes libres](/es/messages/introduction) (dentro de la ventana de 24 h) o [plantillas](/es/messages/send-template) (fuera de la ventana).
  </Step>
</Steps>
