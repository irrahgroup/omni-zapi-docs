## Conceptos

Desconecta un canal `META_MESSENGER` y limpia el vínculo con la cuenta, la página o el bot. Sin cuerpo.

Úsalo para cambiar de página de Facebook o resolver el `422` de [Listar páginas de Messenger](/es/channels/list-messenger-pages), que aparece cuando el canal todavía está activo en el proveedor.

Usa la Secret Key, desde tu backend. No requiere ENTERPRISE.

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DEL_CANAL/deactivate-messenger \
  -H "Authorization: Bearer SU_SECRET_KEY"
```

La respuesta es un booleano. Con `true`, el canal queda desconectado y se limpia el vínculo. Con `false`, nada cambia en el canal.

Para conectar de nuevo, rehaz la conexión con el SDK y finaliza con [Activar Messenger](/es/channels/activate-messenger). Las rutas equivalentes de los otros canales sociales son [Desactivar Instagram](/es/channels/deactivate-instagram), [Desactivar Messenger](/es/channels/deactivate-messenger) y [Desactivar Telegram](/es/channels/deactivate-telegram).

### Errores

| Estado | Cuerpo | Cuándo |
|---|---|---|
| `400` | `{"error":"Authorization invalid"}` | Secret Key ausente, mal formada o inexistente |
| `400` | `{"error":"203.0.113.10 not allowed"}` | IP fuera de la [lista de IPs](/es/security/ip-restriction) |
| `404` | `{"error":"Instance not found"}` | Canal inexistente o de otro workspace |
| `502` | `{"error":"integration_unavailable", ...}` | Falla de integración; vuelve a intentarlo en unos instantes |

<Note>
  El `channelId` se obtiene mediante el endpoint [Crear canal](/es/channels/create-channel) o [Listar canales](/es/channels/list-channels).
</Note>
