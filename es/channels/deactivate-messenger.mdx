## Conceptualización

Desconecta un canal `META_MESSENGER`. La ruta no lleva cuerpo y también marca el canal como desconectado. Para volver a encender el canal, consulta [Activar canal](/es/channels/activate-channel).

## Ejemplo

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DEL_CANAL/deactivate-messenger \
  -H "Authorization: Bearer SU_SECRET_KEY"
```

## Respuesta

`200` con `true`:

```json
true
```

## Errores

Los errores (`401`, `403`, `404`, `422` y `502`) son comunes a las rutas de desconexión y están en [Errores](/es/channels/disconnect#errores).
