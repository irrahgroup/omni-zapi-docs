## Conceptos

Desconecta un canal **`META_WHATSAPP`** de la API Oficial de WhatsApp y borra todos los datos de conexión asociados (WABA ID, phone ID, número conectado y coexistencia).

Usa este endpoint cuando el usuario quiera desconectar el número de forma intencionada, por ejemplo al cambiar de número o al dejar de usar el canal.

<Warning>
  Tras la desconexión, el canal **dejará de recibir mensajes**. Para volver a funcionar, habrá que [reconectar el canal](/es/channels/connect-channel).
</Warning>
