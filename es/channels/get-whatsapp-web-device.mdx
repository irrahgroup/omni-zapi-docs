## Conceptualización

Usa esta ruta para saber qué número y qué dispositivo están vinculados al canal.

## Ejemplo

```bash
curl https://api.omni.z-api.io/v1/channels/ID_DEL_CANAL/zapi/device \
  -H "Authorization: Bearer SU_SECRET_KEY"
```

## Respuesta

La respuesta `200` trae estos campos:

| Campo | Descripción |
|---|---|
| `phone` | Número conectado |
| `imgUrl` | URL de la foto de perfil |
| `name` | Nombre del perfil |
| `device.sessionName` | Nombre de la sesión |
| `device.deviceModel` | Modelo del dispositivo |
| `originalDevice` | Dispositivo original |
| `sessionId` | ID de la sesión |
| `isBusiness` | Si la cuenta es de WhatsApp Business |

## Errores

Los errores (`401`, `403`, `404`, `422` y `502`) son los mismos de las dos rutas y están en [Errores](/es/channels/whatsapp-web-status#errores).
