## Conceptos

Finaliza la conexión de un canal `META_INSTAGRAM`. Es el último paso de [Conectar Instagram](/es/connect/instagram): el SDK devuelve `code` y `redirectUri`, y tu backend llama a esta ruta con los dos. Sin `code`, la API acepta `igId` y `accessToken`.

Usa la Secret Key, desde tu backend. No requiere ENTERPRISE.

```bash
curl -X POST https://api.omni.z-api.io/v1/channels/ID_DEL_CANAL/activate-instagram \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SU_SECRET_KEY" \
  -d '{"code": "AQBx7f...", "redirectUri": "https://app.omni.z-api.io/oauth/proxy-instagram"}'
```

La activación usa la app de Instagram propia del workspace, si existe; si no, la app predeterminada.

Si todo va bien, la respuesta trae la cuenta conectada:

```json
{"id": "17841400000000000", "connected": true, "username": "minhaloja", "name": "Minha Loja", "displayName": "minhaloja"}
```

### Reconexión automática

Si la cuenta ya está activa en el proveedor y el canal está desconectado con suscripción activa (`PAID`, `TRIAL`, `BOLETO_PENDING` o `CANCELLATION_PROCESS`), Z-API Omni deshace la conexión anterior y activa de nuevo por sí solo. En caso contrario, la API responde `422` con el error del proveedor en `error`.

La activación tiene un plazo de 50 segundos. Si lo supera, la API responde `504`: con `integration_timeout`, nada cambió y puedes repetir; con `outcome_unknown`, la conexión anterior ya se deshizo, así que revisa el canal con [Consultar canal](/es/channels/get-channel) antes de repetir.

### Errores

| Estado | Cuerpo | Cuándo |
|---|---|---|
| `400` | `{"error":"Authorization invalid"}` | Secret Key ausente, mal formada o inexistente |
| `400` | `{"error":"203.0.113.10 not allowed"}` | IP fuera de la [lista de IPs](/es/security/ip-restriction) |
| `404` | `{"error":"Instance not found"}` | Canal inexistente o de otro workspace |
| `422` | `{"error":{...}}` | El proveedor rechazó la activación; el error del proveedor viene en `error` |
| `502` | `{"error":"integration_unavailable", ...}` | Falla de integración; vuelve a intentarlo en unos instantes |
| `504` | `{"error":"integration_timeout", ...}` | Superó el plazo de 50 segundos y nada cambió en el canal; puedes repetir |
| `504` | `{"error":"outcome_unknown", ...}` | Superó el plazo después de deshacer la conexión anterior; revisa con [Consultar canal](/es/channels/get-channel) antes de repetir |

### Después de la activación

Revisa el canal con [Consultar canal](/es/channels/get-channel). Para cambiar de cuenta después, desactiva con [Desactivar Instagram](/es/channels/deactivate-instagram) y conecta de nuevo.

<Note>
  El `channelId` se obtiene mediante el endpoint [Crear canal](/es/channels/create-channel) o [Listar canales](/es/channels/list-channels).
</Note>
