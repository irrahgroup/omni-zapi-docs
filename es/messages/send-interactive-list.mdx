## Conceptos

Envía un mensaje con una lista de opciones agrupadas en secciones. El cliente toca el botón, abre la lista y elige una fila.

El campo `content.type` es `INTERACTIVE_LIST`.

Es el formato para cuando las opciones no caben en botones: menú, catálogo de servicios, horarios, sucursales. Hasta 3 opciones, prefiere los [botones de respuesta rápida](/es/messages/send-interactive-button).

## Reglas

Límites publicados por Meta para la lista. La API reenvía la lista como llegó, y Meta rechaza lo que pase del límite.

| Regla | Límite |
|---|---|
| Secciones | 10 |
| Filas | **10 sumando todas las secciones** |
| Texto del botón | 20 caracteres |
| Título de la fila | 24 caracteres |
| Descripción de la fila | 72 caracteres |
| `id` de la fila | único dentro del mensaje |

El límite de filas es **en total**, no por sección.
