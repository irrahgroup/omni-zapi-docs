## Conceptos

Envía un mensaje con una lista de opciones agrupadas en secciones. El cliente toca el botón, abre la lista y
elige una fila; la elección vuelve a tu webhook.

El campo `content.type` será `INTERACTIVE_LIST`.

Es el formato para cuando las opciones no caben en botones: menú, catálogo de servicios, horarios, sucursales.
Hasta 3 opciones, prefiere los [botones de respuesta rápida](/es/messages/send-interactive-button), que exigen
un toque menos.

## Cuerpo de la petición

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "INTERACTIVE_LIST",
    "header": "Menú",
    "message": "Elige una opción",
    "footer": "Entrega en 40 min",
    "button": "Ver opciones",
    "sections": [
      {
        "title": "Pizzas",
        "rows": [
          { "id": "pizza_marg", "title": "Margherita", "description": "Salsa, muzzarella y albahaca" },
          { "id": "pizza_pep", "title": "Pepperoni", "description": "Salsa, muzzarella y pepperoni" }
        ]
      },
      {
        "title": "Bebidas",
        "rows": [
          { "id": "gaseosa_lata", "title": "Gaseosa lata", "description": "350 ml" }
        ]
      }
    ]
  }
}
```

`header` y `footer` son opcionales. El `id` de cada fila lo eliges tú y es lo que vuelve en el webhook cuando
el cliente la selecciona.

## Límites de Meta

| Regla | Límite |
|---|---|
| Secciones | 10 |
| Filas | **10 sumando todas las secciones** |
| Texto del botón | 20 caracteres |
| Título de la fila | 24 caracteres |
| Descripción de la fila | 72 caracteres |
| `id` de la fila | único dentro del mensaje |

<Warning>
  El límite de filas es **total**, no por sección. Diez secciones con diez filas cada una se rechaza — el
  máximo son diez filas repartidas entre las secciones que quieras.
</Warning>

## La respuesta del cliente

Cuando el cliente elige una fila, tu webhook recibe la elección con el mismo `id` que mandaste:

```json
{
  "id": "pizza_marg",
  "title": "Margherita",
  "description": "Salsa, muzzarella y albahaca"
}
```

Es por el `id` que tu aplicación identifica la opción, sin depender del texto mostrado — que puede cambiar sin
romper la integración.
