## Conceptos

Envía un GIF animado. El archivo va por URL en el array `content.attachments`.

El campo `content.type` debe ser `GIF`.

## Cuerpo de la petición

```json
{
  "recipient": {
    "identifier": "5511999999999"
  },
  "content": {
    "type": "GIF",
    "attachments": [
      {
        "url": "https://exemplo.com/comemoracao.gif",
        "caption": "Pedido confirmado!"
      }
    ]
  }
}
```

## Campos

| Campo | Obligatorio | Descripción |
|---|:---:|---|
| `content.attachments` | sí | Lista con el GIF |
| `content.attachments[].url` | no | URL del archivo |
| `content.attachments[].mimeType` | no | Tipo del archivo |
| `content.attachments[].caption` | no | Leyenda |
| `content.attachments[].id` | no | Identificador del archivo |

<Note>
  Sin `content.attachments`, la API responde `400` con `code` `VALIDATION_ERROR` y `message` `"Field 'content.attachments': is required for message type GIF"`, y el mensaje no se envía.
</Note>

<Note>
  La API no rechaza este tipo por canal antes del envío. El `200` confirma que la API aceptó el mensaje, no que el canal lo entregó: sigue el estado por el [webhook](/es/webhooks/payloads). Consulta [qué acepta cada canal](/es/channels/message-support).
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  Cuando el envío es aceptado, la API responde `200` con el `messageId`. Consulta [Respuesta de la API](/es/messages/introduction#respuesta-de-la-api).
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-gif` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `GIF`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be GIF on /send-gif; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, y el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
