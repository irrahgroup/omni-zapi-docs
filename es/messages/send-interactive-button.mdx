## Conceptos

Envía un mensaje de texto con botones de respuesta rápida. El campo `content.type` debe ser `INTERACTIVE_BUTTON`. El destinatario puede elegir entre las opciones que se le presentan.

Opcionalmente puedes incluir una **imagen** o un **vídeo** junto con el mensaje usando los campos `thumbnail` y `mimeType` dentro de `body`.

<Note>
  Detalles de la regla de Meta Cloud API en [ventana de conversación](/es/conversation-window). Consulta [qué acepta cada canal](/es/channels/message-support) para todos los canales.
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-button-list` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `INTERACTIVE_BUTTON`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be INTERACTIVE_BUTTON on /send-button-list; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, y el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
