## Conceptos

Envía un formulario de WhatsApp, un [Flow](/es/flows/introduction) ya publicado, directo en la conversación,
**sin plantilla y sin aprobación**. El cliente toca el botón y el formulario se abre en el propio WhatsApp. El
campo `content.type` debe ser `INTERACTIVE_FLOW`.

## Campos

| Campo | Regla |
|---|---|
| `body.message` | Obligatorio. Texto del mensaje, encima del botón |
| `header.message` | Opcional. Título en texto |
| `footer.message` | Opcional. Pie |
| `action.name` | Obligatorio. Siempre `flow` |
| `action.version` | Obligatorio. Versión del mensaje de Flow en Meta: `3` |
| `action.id` | Obligatorio. El `id` de un formulario publicado en la misma cuenta del canal, como viene en [Listar flows](/es/flows/list-flows) |
| `action.cta` | Obligatorio. Texto del botón, hasta 30 caracteres |
| `action.mode` | Opcional. Sin él, vale `published` |

No hay forma de elegir la pantalla de apertura, mandarle datos ni enviar un token de sesión.

<Warning>
  La respuesta que el cliente completa todavía no llega a tu webhook con los campos del formulario.
</Warning>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>
