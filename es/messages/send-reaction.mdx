## Conceptos

Aplica un emoji a un mensaje que ya está en la conversación. Para quitarlo, manda la misma reacción con el
emoji vacío.

El campo `content.type` será `REACTION`.

## Cuerpo de la petición

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "REACTION",
    "messageId": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNBMDI...",
    "emoji": "👍"
  }
}
```

Para quitarla, manda `"emoji": ""`.

## Reglas

| Regla | Valor |
|---|---|
| Edad del mensaje objetivo | menos de **30 días** |
| Emoji | uno solo, como carácter o secuencia unicode |
| Reaccionar a una reacción | no se acepta |
| Mensaje borrado | no se acepta |

<Note>
  La reacción solo genera webhook de **enviado**. No hay confirmación de entrega ni de lectura. Un objetivo
  inválido vuelve con el código `131009`.
</Note>
