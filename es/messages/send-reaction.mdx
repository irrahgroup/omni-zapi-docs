## Conceptos

Aplica un emoji a un mensaje que ya está en la conversación, enviado por ti o recibido del cliente. El campo
`content.type` debe ser `REACTION`.

| Campo | Qué va en él |
|---|---|
| `body.id` | El `messageId` del mensaje objetivo: el que la API devolvió en el envío, o el `message._id` que llegó en el [webhook](/es/webhooks/payloads) del mensaje recibido |
| `body.message` | El emoji, uno solo |

## Reglas de Meta Cloud API

| Regla | Valor |
|---|---|
| Edad del mensaje objetivo | menos de **30 días** |
| Emoji | uno solo, como carácter o secuencia unicode |
| Reaccionar a una reacción | no se acepta |
| Mensaje borrado | no se acepta |

<Warning>
  El `body.id` es obligatorio. Sin él, la API acepta la llamada con `200`, pero la reacción no se envía.
</Warning>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>
