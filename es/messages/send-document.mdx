## Conceptos

Envía un archivo al contacto. WhatsApp elige el ícono según la extensión y el nombre que informes.

El campo `content.type` será `DOCUMENT`.

## Cuerpo de la petición

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "DOCUMENT",
    "attachments": [
      {
        "url": "https://tutienda.com/factura.pdf",
        "fileName": "factura.pdf",
        "caption": "Aquí está tu factura"
      }
    ]
  }
}
```

## Reglas

| Regla | Valor |
|---|---|
| Tamaño | hasta 100 MB |
| Tipos | PDF, Word, Excel, PowerPoint, texto |
| Leyenda | hasta 1024 caracteres |
| `fileName` | **con la extensión** — es la que define el ícono que ve el cliente |

<Warning>
  El `fileName` va con la extensión, como `factura.pdf`. Hoy hay un defecto conocido en ese campo en la capa
  de compatibilidad Z-API: con extensión el archivo llega como `factura.pdf.pdf`, y sin ella llega como
  `factura.null`.
</Warning>
