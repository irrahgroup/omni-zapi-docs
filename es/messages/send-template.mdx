## Conceptos

Envía a un contacto una plantilla de mensaje aprobada por Meta. Es la **única forma** de enviar mensajes fuera de la [ventana de conversación](/es/conversation-window) de 24 horas.

El campo `content.type` debe ser `TEMPLATE` y la plantilla se envía dentro de `attachments`.

<Warning>
  La plantilla debe tener el estado `APPROVED` para poder usarse. Utiliza los endpoints de [Plantillas](/es/templates/introduction) para crear y gestionar tus plantillas.
</Warning>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>
