## Conceptos

Envía a un contacto una plantilla de mensaje aprobada por Meta. Es la **única forma** de enviar mensajes fuera de la [ventana de conversación](/es/conversation-window) de 24 horas.

El campo `content.type` debe ser `TEMPLATE` y la plantilla se envía dentro de `attachments`.

<ChannelSupport type="TEMPLATE" lang="es" />

<Warning>
  Las plantillas son un recurso **exclusivo de Meta Cloud API**. No existen en los demás canales, y ahí no hacen falta porque no hay ninguna ventana que reabrir. Consulta [qué acepta cada canal](/es/channels/message-support).
</Warning>

<Warning>
  La plantilla debe tener el estado `APPROVED` para poder usarse. Utiliza los endpoints de [Plantillas](/es/templates/introduction) para crear y gestionar tus plantillas.
</Warning>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  La plantilla solo sale por canales Meta Cloud API (`META_WHATSAPP`) o Messenger (`META_MESSENGER`). En otro canal, `POST /v1/channels/{channelId}/messages` responde `422` con `code` `BUSINESS_RULE_VIOLATION` y `subCode` `TEMPLATE_NOT_SUPPORTED`, y el mensaje no se envía:

  ```json
  {
    "timestamp": "2026-10-22T14:00:00.123Z",
    "code": "BUSINESS_RULE_VIOLATION",
    "subCode": "TEMPLATE_NOT_SUPPORTED",
    "message": "TEMPLATE messages are only supported on META_WHATSAPP and META_MESSENGER channels"
  }
  ```
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-template` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `TEMPLATE`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be TEMPLATE on /send-template; leave it out, or send other types with POST /v1/channels/{id}/messages"}`. La ruta solo acepta canales Meta Cloud API (WhatsApp Oficial): en otro canal, la API responde `422` `{"error": "operation not supported for this instance"}`. En los dos casos, el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
