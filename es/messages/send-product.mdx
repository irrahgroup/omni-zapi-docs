## Conceptos

Envía un único producto del catálogo. La foto, el nombre y el precio vienen de Commerce Manager.

El campo `content.type` debe ser `INTERACTIVE_SINGLE_PRODUCT`.

## Cuerpo de la petición

```json
{
  "recipient": {
    "identifier": "5511999999999"
  },
  "content": {
    "type": "INTERACTIVE_SINGLE_PRODUCT",
    "body": {
      "message": "Este é o produto que você perguntou."
    },
    "footer": {
      "message": "Estoque limitado"
    },
    "action": {
      "catalogId": "1234567890",
      "productRetailerId": "SKU-1042"
    }
  }
}
```

## Campos

| Campo | Obligatorio | Descripción |
|---|:---:|---|
| `content.body` | sí | Cuerpo del mensaje. Puede ir vacío (`{}`) |
| `content.body.message` | no | Texto del mensaje |
| `content.footer.message` | no | Pie |
| `content.action.catalogId` | no | Id del catálogo en Commerce Manager. Meta lo exige |
| `content.action.productRetailerId` | no | SKU (`retailer_id`) del producto. Meta lo exige |

## Reglas

| Regla | Valor |
|---|---|
| `catalogId` y `productRetailerId` | la API no los revisa antes del envío: sin ellos, o con un SKU que no existe, Meta rechaza después del `200` y el mensaje no llega |

<Note>
  Sin `content.body`, la API responde `400` con `code` `VALIDATION_ERROR` y `message` `"Field 'content.body': is required for message type INTERACTIVE_SINGLE_PRODUCT"`, y el mensaje no se envía.
</Note>

<Note>
  En los demás canales, la API no rechaza este tipo antes del envío: responde `200`, pero el mensaje no llega al cliente.
</Note>

<Note>
  Detalles de la regla de Meta Cloud API en [ventana de conversación](/es/conversation-window). Consulta [qué acepta cada canal](/es/channels/message-support) para todos los canales.
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  Cuando el envío es aceptado, la API responde `200` con el `messageId`. Consulta [Respuesta de la API](/es/messages/introduction#respuesta-de-la-api).
</Note>

<Note>
  Este tipo no tiene ruta `send-*` propia: `send-product` responde `422` `send_route_not_supported`. Envíalo por `POST /v1/channels/{channelId}/messages`.
</Note>
