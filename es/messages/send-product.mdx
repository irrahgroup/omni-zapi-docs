## Conceptos

Envía un único producto del catálogo. La foto, el nombre y el precio salen de Commerce Manager.

El campo `content.type` será `PRODUCT`.

## Cuerpo de la petición

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "PRODUCT",
    "message": "Este es el producto por el que preguntaste.",
    "footer": "Stock limitado",
    "catalogId": "1234567890",
    "productRetailerId": "SKU-1042"
  }
}
```

## Reglas

| Regla | Valor |
|---|---|
| `catalogId` y `productRetailerId` | los dos obligatorios |
| Mensaje y pie | opcionales |
| SKU inexistente | Meta lo rechaza y no entrega el mensaje |
