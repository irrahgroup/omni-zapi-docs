## Conceptos

Manda un mensaje que abre el catálogo conectado a tu cuenta en Commerce Manager.

El campo `content.type` debe ser `INTERACTIVE_CATALOG`.

<ChannelSupport type="CATALOG" lang="es" />

## Cuerpo de la petición

```json
{
  "recipient": {
    "identifier": "5511999999999"
  },
  "content": {
    "type": "INTERACTIVE_CATALOG",
    "body": {
      "message": "Chegaram novidades na loja. Toque para ver o catálogo completo."
    },
    "footer": {
      "message": "Preços válidos enquanto durar o estoque"
    },
    "action": {
      "id": "SKU-1042"
    }
  }
}
```

## Campos

| Campo | Obligatorio | Descripción |
|---|:---:|---|
| `content.body` | sí | Cuerpo del mensaje |
| `content.body.message` | no | Texto del mensaje. Meta exige el texto y acepta hasta 1024 caracteres |
| `content.footer.message` | no | Pie. Meta acepta hasta 60 caracteres |
| `content.action.id` | no | SKU (`retailer_id`) del producto que aparece en la portada. Sin él, Meta usa el primer ítem del catálogo |

## Reglas

| Regla | Valor |
|---|---|
| Catálogo | debe estar conectado a la cuenta en Commerce Manager |
| Límites de Meta | la API no revisa los tamaños antes del envío; el rechazo de Meta llega después del `200` |

<Note>
  Sin `content.body`, la API responde `400` con `code` `VALIDATION_ERROR` y `message` `"Field 'content.body': is required for message type INTERACTIVE_CATALOG"`, y el mensaje no se envía.
</Note>

<Note>
  En los demás canales, la API no rechaza este tipo antes del envío: responde `200`, pero el mensaje no llega al cliente.
</Note>

<Note>
  Detalles de la regla de Meta Cloud API en [ventana de conversación](/es/conversation-window). Consulta [qué acepta cada canal](/es/channels/message-support) para todos los canales.
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  Cuando el envío es aceptado, la API responde `200` con el `messageId`. Consulta [Respuesta de la API](/es/messages/introduction#respuesta-de-la-api).
</Note>

<Note>
  Este tipo no tiene ruta `send-*` propia: `send-catalog` responde `422` `send_route_not_supported`. Envíalo por `POST /v1/channels/{channelId}/messages`.
</Note>
