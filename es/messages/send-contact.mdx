<Warning>
  **En implementación.** Se envían todos los contactos de `attachments`, y cada canal los entrega a su manera:

  - **WhatsApp Oficial y WhatsApp Web:** todos los contactos llegan en un solo mensaje.
  - **Telegram:** cada teléfono de cada contacto se convierte en un mensaje.
  - **Instagram:** la API rechaza el envío en el acto, con `422`.
  - **Messenger:** el canal no tiene tarjeta de contacto. La API responde `200`, pero el mensaje no llega.

  De cada contacto, solo llevamos `name` y `phones`. [Meta acepta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/contacts-messages) también correo, dirección, organización, cumpleaños y sitio web. Para enviar varios contactos, consulta también [Enviar varios contactos](/es/messages/send-contacts).
</Warning>

## Conceptos

Envía un contacto a un destinatario. El campo `content.type` debe ser `CONTACT`. Puedes enviar varios teléfonos en el array `phones`.

<ChannelSupport type="CONTACT" lang="es" />

<Note>
  Detalles de la regla de Meta Cloud API en [ventana de conversación](/es/conversation-window). Consulta [qué acepta cada canal](/es/channels/message-support) para todos los canales.
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-contact` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `CONTACT`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be CONTACT on /send-contact; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, y el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
