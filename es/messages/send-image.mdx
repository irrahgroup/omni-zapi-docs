## Conceptos

Envía un mensaje con imagen a un contacto. El campo `content.type` debe ser `IMAGE` y la imagen se envía mediante una URL dentro del array `attachments`.

Opcionalmente puedes incluir un `caption` (pie de foto) junto con la imagen.

<ChannelSupport type="IMAGE" lang="es" />

<Note>
  Detalles de la regla de Meta Cloud API en [ventana de conversación](/es/conversation-window). Consulta [qué acepta cada canal](/es/channels/message-support) para todos los canales.
</Note>

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-image` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `IMAGE`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be IMAGE on /send-image; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, y el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
