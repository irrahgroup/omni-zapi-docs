## Conceptos

Envía un mensaje con botones de acción a un contacto. El campo `content.type` debe ser `INTERACTIVE_ACTION`.

Tipos de botón disponibles:

- **URL** — Abre un enlace al pulsarlo
- **CALL** — Llama a un número al pulsarlo

Los campos `header` y `footer` son opcionales.

<Note>
  Con el canal desconectado, la API rechaza el envío con `422` y `subCode` `CHANNEL_DISCONNECTED`, y el mensaje no se envía. Consulta [Errores al enviar](/es/messages/introduction#errores-al-enviar).
</Note>

<Note>
  La ruta `POST /v1/channels/{channelId}/send-button-actions` acepta el mismo cuerpo de esta página y da la misma respuesta. En ella, `content.type` es opcional y, si lo envías, debe ser `INTERACTIVE_ACTION`. Con otro valor, la API responde `400` `{"error": "invalid_request", "field": "content.type", "message": "content.type must be INTERACTIVE_ACTION on /send-button-actions; leave it out, or send other types with POST /v1/channels/{id}/messages"}`, y el mensaje no se envía. Consulta [Rutas por tipo](/es/messages/introduction#rutas-por-tipo).
</Note>
