## Conceptos

Manda un mensaje con el botón **Enviar ubicación**. El cliente lo toca y WhatsApp devuelve su punto a tu
webhook.

Es lo contrario de [enviar ubicación](/es/messages/send-location): acá quien manda el punto es el cliente.

El campo `content.type` será `LOCATION_REQUEST`.

## Cuerpo de la petición

```json
{
  "recipient": { "identifier": "5511999999999" },
  "content": {
    "type": "LOCATION_REQUEST",
    "message": "Para calcular el envío, toca abajo y manda tu ubicación."
  }
}
```

## Reglas

| Regla | Valor |
|---|---|
| Texto | hasta 1024 caracteres |
| Etiqueta del botón | fija de WhatsApp, traducida al idioma del cliente |

La respuesta llega como un mensaje de ubicación común, con latitud, longitud y, cuando el cliente lo permite,
nombre y dirección.
