## Conceptos

Cambia el texto de un mensaje de texto que tu canal ya envió. El destinatario ve el texto nuevo en lugar del anterior, con la marca de editado de la aplicación. No se envía ningún mensaje nuevo.

El `messageId` del path es el que devolvió el envío. También se acepta el `contents[].identifier` recibido en el webhook. El destinatario y el remitente no se piden: valen los del mensaje original. Solo se puede editar texto: la leyenda de una imagen, un video o un documento recibe `422` `MESSAGE_NOT_EDITABLE`.

<Note>
  El `200` confirma que la edición fue aceptada y enviada al canal, no que la aplicación del contacto ya muestre el texto nuevo. Si el canal rechaza después, por ejemplo si el contacto bloqueó el bot en Telegram o el mensaje fue eliminado, el texto del contacto no cambia y la API no envía aviso de ese rechazo.
</Note>

## Errores

| Status | Cuándo |
|---|---|
| 400 | cuerpo ausente o vacío, `content.type` distinto de `TEXT` o `content.body.message` vacío |
| 404 | el `messageId` no existe o no es de este canal |
| 422 `EDIT_NOT_SUPPORTED` | el canal no permite edición |
| 422 `CHANNEL_DISCONNECTED` | el canal está desconectado |
| 422 `MESSAGE_NOT_EDITABLE` | el mensaje no es texto (incluida la leyenda de un archivo), no lo envió tu canal, el canal todavía no lo aceptó o falló al enviarse |
| 422 `EDIT_WINDOW_EXPIRED` | pasó el plazo en que el canal acepta edición |

Trata los rechazos por el `subCode`. El texto de `message` puede cambiar.
