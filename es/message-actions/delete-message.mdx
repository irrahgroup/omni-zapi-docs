## Concepto

Elimina el mensaje para todos.

<Note>
  La eliminación es **asíncrona**: el `200` confirma que el pedido fue aceptado; el resultado llega después. La respuesta trae el `messageId` del **propio mensaje eliminado** — el mismo id de la ruta.
</Note>
