## Conceptos

Método que acepta una invitación recibida para participar en un grupo. La URL de la invitación se puede obtener por el webhook de mensaje recibido.

<Warning>
  En WhatsApp Oficial esta ruta no está disponible y responde `422`: la [Groups API de Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference) no tiene una ruta equivalente.
</Warning>
