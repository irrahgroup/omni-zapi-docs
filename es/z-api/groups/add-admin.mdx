## Conceptos

Método que promueve participantes del grupo a administradores. Puedes promover a uno o más participantes.

<Warning>
  En WhatsApp Oficial esta ruta no está disponible y responde `422`: la empresa es la creadora y [administradora del grupo](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference), y la Groups API de Meta no tiene una ruta para promover o quitar administradores.
</Warning>
