## Conceptos

Método que devuelve el metadata del grupo, con toda la información del grupo y de sus participantes, excepto el enlace de invitación.

La única diferencia con [Metadata del grupo](/es/z-api/groups/group-metadata) es que este no devuelve el enlace de invitación, porque en ciertos momentos obtener el enlace es costoso y algo lento. Si necesitas el enlace, usa [Obtener enlace de invitación](/es/z-api/groups/group-invitation-link).

<Warning>
  En WhatsApp Oficial, los campos tienen los mismos valores de [Metadata del grupo](/es/z-api/groups/group-metadata), con `invitationLink` siempre `null`.
</Warning>
