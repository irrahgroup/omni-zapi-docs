## Conceptos

Método que hace que el número conectado salga de un grupo en el que participa.

<Warning>
  En WhatsApp Oficial esta ruta no está disponible y responde `422`. La [Groups API de Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group) no tiene la acción de salir del grupo, solo la de eliminar el grupo, que quita a todos los participantes, incluida la empresa. Esta ruta no la hace: el grupo no se elimina.
</Warning>
