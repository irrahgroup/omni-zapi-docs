## Conceptos

Método que redefine el enlace de invitación de un grupo. La ruta no recibe cuerpo: el grupo va en la ruta.

<Warning>
  En WhatsApp Oficial, el [enlace anterior deja de valer](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-and-reset-group-invite-link) y la respuesta trae solo `invitationLink`, con el enlace nuevo.
</Warning>
