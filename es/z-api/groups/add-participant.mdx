## Conceptos

Método que agrega nuevos participantes al grupo.

Para incluir participantes, usa solo el número de teléfono. El identificador `@lid` no es compatible y no agrega al miembro.

<Warning>
  En WhatsApp Oficial esta ruta no está disponible y responde `422`: [Meta no permite agregar participantes manualmente](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#create-group), y la entrada es solo por el enlace de invitación. Obtén el enlace con [Obtener enlace de invitación](/es/z-api/groups/group-invitation-link) y compártelo con el contacto.
</Warning>
