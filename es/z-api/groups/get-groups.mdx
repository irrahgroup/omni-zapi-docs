## Conceptos

Método que devuelve los grupos del canal. Usa el campo `phone` de cada elemento como ID del grupo en las demás rutas de esta sección.

Envía `page` y `pageSize` para paginar el resultado.

<Warning>
  En WhatsApp Oficial, la lista trae los [grupos activos del número](https://developers.facebook.com/documentation/business-messaging/whatsapp/groups/reference#get-active-groups) en la Groups API de Meta, y `page` y `pageSize` son opcionales (valen `1` y `10`).
</Warning>
