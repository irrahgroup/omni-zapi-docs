## Conceptos

Método que informa si el canal está conectado. La respuesta trae `connected`, el texto `error` con el detalle del estado y `smartphoneConnected`.

El estado considera solo la conexión del canal. La situación de la suscripción no forma parte de él.

<Warning>
  Fuera de WhatsApp Web no hay un celular conectado, así que `smartphoneConnected` siempre acompaña a `connected`.
</Warning>
