## ¿Qué es la versión Compatibilidad con Z-API?

La versión **Compatibilidad con Z-API** responde en el formato de Z-API. Quien ya integra Z-API migra a Z-API Omni cambiando la base URL y el header de autenticación, y sigue enviando los mismos cuerpos y leyendo las mismas respuestas. La dirección es `https://zapi.omni.z-api.io`.

Atiende **solo canales WhatsApp Oficial** (`META_WHATSAPP`, la API oficial de Meta). Las rutas de Z-API que WhatsApp Oficial no tiene, o que todavía no están disponibles, se rechazan con una respuesta clara. La lista completa está en [Limitaciones y rechazos](/es/z-api/limitations).

<Warning>
  Un envío a un canal de otro tipo (WhatsApp Web, Instagram, Messenger o Telegram) se rechaza con `422`:

  ```json
  { "error": "instance middleware is not META_WHATSAPP" }
  ```

  Un canal WhatsApp Oficial sin suscripción activa también recibe `422`, con `{ "error": "instance subscription is not active" }`. Para enviar por los otros canales, usa las [rutas de mensajes de Z-API Omni](/es/messages/introduction).
</Warning>

## Qué cambia en la práctica

|  | Z-API | Z-API Omni |
|---|---|---|
| **Base URL** | `https://api.z-api.io` | `https://zapi.omni.z-api.io` |
| **Autenticación** | Header `Client-Token` | Header `Authorization` con la Secret Key, con o sin `Bearer` ([Autenticación](/es/z-api/authentication)) |
| **Path** | `/instances/{id}/token/{token}/...` | `/instances/`, `/devices/` o `/channels/` (equivalentes) |
| **Nomenclatura** | `instance_id` | `channel_id` |
| **Cuerpo y respuesta de los envíos** | Formato Z-API | El mismo formato en las rutas que envían ([Mensajes](/es/z-api/messages/introduction)) |
| **Webhooks** | Formato Z-API | Configura `payloadFormat` `Z_API` en el webhook del canal o en el webhook predeterminado ([Webhooks](/es/webhooks/introduction)) |

### Sobre la nomenclatura

En Z-API Omni, lo que antes se llamaba **instancia** (`instance_id`) se trata como **canal** (`channel_id`). El concepto es el mismo: la conexión con un número de WhatsApp. El término "canal" es más amplio porque Z-API Omni tiene otros canales de mensajes además de WhatsApp.

<Note>
  La API acepta `/instances/`, `/devices/` y `/channels/` en el path, con el mismo comportamiento. Quien migra desde Z-API puede mantener `/instances/`. En integraciones nuevas, usa `/channels/`.
</Note>

Si hoy tu aplicación hace una llamada como esta:

```bash
curl -X POST https://api.z-api.io/instances/SU_INSTANCIA/token/SU_TOKEN/send-text \
  -H "Content-Type: application/json" \
  -H "Client-Token: SU_CLIENT_TOKEN" \
  -d '{"phone": "5511999999999", "message": "¡Hola!"}'
```

Cambia la base URL y el header de autenticación:

```bash
curl -X POST https://zapi.omni.z-api.io/channels/SU_CANAL/token/SU_TOKEN/send-text \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SU_SECRET_KEY" \
  -d '{"phone": "5511999999999", "message": "¡Hola!"}'
```

`SU_CANAL` es el `id` del canal y `SU_TOKEN` es su `token`, devueltos al [crear el canal](/es/channels/create-channel) y al [consultarlo](/es/channels/get-channel). La Secret Key se genera en el menú **Seguridad** del panel.

## Qué cubre la compatibilidad

| Grupo | Qué responde |
|---|---|
| [Mensajes](/es/z-api/messages/introduction) | 42 rutas `send-*` y de pedido. Una parte envía y otra se rechaza con `422`. Cada ruta está en la tabla de la introducción de mensajes |
| [Instancia](/es/z-api/instance/status) | `status`, `me`, `device` y la cola (`queue`), en el formato de Z-API |
| Rutas de Z-API sin equivalente | 149 rutas (grupos, contactos, chats, catálogo, comunidades, canales, perfil comercial, privacidad y etiquetas, entre otras) rechazadas con `422` |
| Otras rutas | Un método incorrecto responde `405`; una ruta que no existe responde `404` |

La respuesta de cada caso está en [Limitaciones y rechazos](/es/z-api/limitations).

## Cómo migrar

<Steps>
  <Step title="Crea tu cuenta en Z-API Omni">
    Entra al [Dashboard](https://app.omni.z-api.io) y crea tu cuenta.
  </Step>
  <Step title="Crea y conecta un canal WhatsApp Oficial">
    Crea un canal de tipo WhatsApp Oficial y conecta el número. Consulta [Conectar WhatsApp Oficial](/es/connect/meta-whatsapp).
  </Step>
  <Step title="Actualiza la base URL y la autenticación">
    Cambia `https://api.z-api.io` por `https://zapi.omni.z-api.io` y el header `Client-Token` por `Authorization: Bearer SU_SECRET_KEY`.
  </Step>
  <Step title="Revisa las rutas que usas">
    Compara las rutas de tu integración con [Mensajes](/es/z-api/messages/introduction) y con [Limitaciones y rechazos](/es/z-api/limitations). Una ruta rechazada responde `422` con el motivo y no se envía nada.
  </Step>
  <Step title="Configura los webhooks">
    Apunta los webhooks del canal a tu servidor y usa `payloadFormat` `Z_API` para mantener el formato. Consulta [Webhooks](/es/webhooks/introduction).
  </Step>
  <Step title="Prueba y valida">
    Prueba el envío y la recepción antes de pasar el tráfico de producción.
  </Step>
</Steps>
