## Conceptos

Método para cambiar los sitios web de la empresa en el perfil comercial de WhatsApp Business. Envía las URL en `websites`, como máximo 2. En WhatsApp Web, una lista vacía elimina los sitios web, como en Z-API.

<Warning>
  En WhatsApp Oficial, cada sitio web tiene como máximo 256 caracteres y debe empezar por `http://` o `https://`, [límites de Meta](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles). Si Meta rechaza el valor, la respuesta es `422` con `the channel provider refused the request`.
</Warning>
