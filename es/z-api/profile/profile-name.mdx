## Conceptos

Método para cambiar el nombre del perfil del número de WhatsApp conectado al canal. Envía el nombre en `value`.

Funciona en canales de **WhatsApp Web**. Para cambiar el nombre del canal en {projectName}, usa [Renombrar canal](/es/z-api/profile/update-name).

<Warning>
  En WhatsApp Oficial, la ruta responde `422` con `profile name changes on META_WHATSAPP channels require Meta review: use WhatsApp Manager`. El cambio del nombre visible pasa por una nueva [revisión de Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/display-names).
</Warning>
