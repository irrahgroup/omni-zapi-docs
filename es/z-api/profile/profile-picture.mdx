## Conceptos

Método para cambiar la imagen de perfil del número de WhatsApp conectado al canal. Envía en `value` la URL de la imagen.

<Warning>
  En WhatsApp Oficial, `value` debe ser una URL `http` o `https`: otro formato, como Base64, responde `422` con `profile picture on META_WHATSAPP channels must be an http or https URL`. La foto no se puede eliminar: un `value` vacío responde `422` con `the profile picture cannot be removed on META_WHATSAPP channels`.
</Warning>
