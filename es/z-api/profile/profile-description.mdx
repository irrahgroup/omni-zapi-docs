## Conceptos

Método para cambiar la descripción del perfil del número de WhatsApp conectado al canal. Envía el texto en `value`.

En WhatsApp Oficial, la descripción es el texto **Info** (`about`) del perfil.

<Warning>
  En WhatsApp Oficial, el texto tiene de 1 a 139 caracteres, un [límite de Meta](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/business-profiles). Si Meta rechaza el valor, la respuesta es `422` con `the channel provider refused the request`.
</Warning>
