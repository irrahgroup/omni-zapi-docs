## Conceptos

Método que devuelve los mensajes que están en la cola a la espera de procesamiento, paginados por `page` y `pageSize`.

Z-API considera esta ruta obsoleta. Para integraciones nuevas, usa [Cola](/es/z-api/queue/post-queue), con paginación por cursor.

<Warning>
  Fuera de WhatsApp Web no hay cola: `page` y `pageSize` se ignoran y `messages` viene siempre vacío.
</Warning>
