## Conceptos

Método que devuelve los mensajes que están en la cola a la espera de procesamiento, con paginación por cursor. Sin cuerpo, se devuelve la primera página.

Usa el `pagingState` de la respuesta para pedir la página siguiente y detente cuando `hasMore` sea `false`. `pageSize` tiene valor predeterminado 20 y máximo 30.

<Warning>
  Fuera de WhatsApp Web no hay cola: el cuerpo no se lee y la respuesta es siempre una página vacía y última, con `messages` vacío, `pagingState` `null` y `hasMore` `false`.
</Warning>
