## Cómo responden los rechazos

La compatibilidad atiende solo canales WhatsApp Oficial (`META_WHATSAPP`). Lo que no envía o no tiene responde siempre en JSON, después de la [autenticación](/es/z-api/authentication), y no se envía nada:

| Caso | Status | Cuerpo |
|---|---|---|
| Ruta de envío rechazada | `422` | `{"error": "<motivo>"}`, en la tabla [Envío rechazado](#envío-rechazado) |
| Ruta de Z-API sin equivalente | `422` | `{"error": "<familia> route is not available for META_WHATSAPP channels; available only on Z-API (WhatsApp Web) instances"}` |
| Método incorrecto para una ruta que existe | `405`, con el header `Allow` | `{"error": "method not allowed: use POST"}`, con los métodos aceptados en lugar de `POST` |
| Ruta que no existe en la compatibilidad | `404` | `{"error": "route not found: this route does not exist in the Z-API compatibility"}` |
| Canal de otro tipo, en una ruta de envío | `422` | `{"error": "instance middleware is not META_WHATSAPP"}` |
| Canal sin suscripción activa, en una ruta de envío | `422` | `{"error": "instance subscription is not active"}` |

Cuando el canal no es WhatsApp Oficial, el nombre del tipo de canal reemplaza a `META_WHATSAPP` en el mensaje de rechazo de las rutas sin equivalente.

## Envío rechazado

Estas rutas existen en la compatibilidad, pero **no envían**. La respuesta es `422`, sin `zaapId` ni `messageId`.

| Ruta | Respuesta `error` |
|---|---|
| `send-button-pix` | `pix button is not supported for this channel` |
| `send-poll` | `poll is not supported for this channel` |
| `send-order` | `order is not supported for this channel` |
| `send-link-list` | `link list is not supported for this channel` |
| `send-carousel` | `carousel is not available for this channel yet` |
| `send-catalog` | `catalog message is not available for this channel yet` |
| `send-product` | `product message is not available for this channel yet` |
| `send-option-multi-list` | `multi-section option list is not available for this channel yet` |
| `send-option-list` | `option list is not available for this channel yet`. El payload se verifica antes: un error de él (por ejemplo `optionList.options is required`) viene en lugar de este mensaje |
| `send-text-status`, `send-image-status`, `send-video-status` | `status (stories) route is not available for META_WHATSAPP channels; available only on Z-API (WhatsApp Web) instances` |
| Cualquier ruta de envío con `editMessageId` o `editDocumentMessageId` | `message editing is not supported for this channel` |

Los mensajes con "is not supported" son de funciones que WhatsApp Oficial no tiene. Los que dicen "is not available ... yet" son de funciones que todavía no están disponibles por esta ruta.

### Rutas sin contenido convertido

Estas rutas existen, pero el cuerpo en el formato de Z-API no se convierte en un mensaje. La respuesta es `422` con `{"error": "message has no content this route can send"}`, y no se envía nada:

- `send-poll-vote`
- `send-call`
- `send-chat-expiration` (el valor de `chatExpiration` se verifica antes: `24_HOURS`, `7_DAYS`, `90_DAYS` u `OFF`)
- `send-event`, `send-edit-event` y `send-event-response`
- `send-comment`
- `send-request-payment`
- `order-status-update` y `order-payment-update`
- `send-newsletter-admin-invite`

La misma respuesta vale para cualquier envío cuyo contenido sería un texto vacío, por ejemplo `send-messages` con un `message` solo con espacios o `send-button-otp` sin `code` y `message`.

## Rechazos por campo en rutas que envían

| Ruta | Cuándo | Respuesta `error` |
|---|---|---|
| `send-button-actions` | Botón `CALL` | `call button is not supported for this channel` |
| `send-button-actions` | Botón `URL` con el enlace de copiar código (`whatsapp.com/otp/code`) | `copy button is not supported for this channel` |
| `send-button-actions` | Botones `URL` y `REPLY` juntos | `URL and REPLY buttons cannot be sent together on this channel` |
| `send-button-actions` | Más de un botón `URL` | `only one URL button is supported for this channel` |
| `send-button-actions` | Botón `URL` con `image` | `image header with a URL button is not available for this channel yet` |
| `send-button-actions` | Botones `REPLY` con `title` o `footer` | `title and footer with REPLY buttons are not available for this channel yet` |
| `send-button-list` | `headerImage` y `headerVideo` juntos | `buttonList accepts headerImage or headerVideo, not both` |

Los límites de tamaño y de cantidad están en [Enviar botones de acción](/es/z-api/messages/send-button-actions) y [Enviar lista de botones](/es/z-api/messages/send-button-list).

## Rutas que envían con diferencia

| Función | Qué ocurre |
|---|---|
| Responder con cita (`messageId` en los envíos) | El campo se acepta, pero el mensaje llega sin citar el original |
| Respuesta privada en grupo (`privateAnswer`) | El campo no se lee |
| `send-gif` | Se envía como imagen |
| `send-ptv` | Se envía como video común, no como video circular |
| `delayMessage` y `delayTyping` | Los valores superiores a 15 se reducen a 15 |
| `mentioned` | Solo en conversación de grupo. Fuera de ella: `400` con `mentions are only allowed in groups` |

## Rutas de Z-API sin equivalente

Son 149 rutas de Z-API. Todas responden `422` con `<familia> route is not available for META_WHATSAPP channels; available only on Z-API (WhatsApp Web) instances`, después de la autenticación. Cada tabla trae el nombre de la familia que entra en el mensaje.

Los métodos que la tabla tiene para una ruta son los únicos que responden `422`. Otro método responde `405`.

Los webhooks, las rutas de integrador y las rutas on-demand de Z-API no tienen equivalente en la compatibilidad y responden `404`, como cualquier ruta que no existe.

<Info>
  Para canales WhatsApp Web, Z-API Omni tiene rutas propias, fuera de la compatibilidad: [QR Code](/es/channels/zapi-qr-code), [estado](/es/channels/zapi-status), [desconectar](/es/channels/zapi-disconnect) y [dispositivo](/es/channels/zapi-device).
</Info>

## Rutas de instancia que la compatibilidad atiende

`GET /status`, `GET /me`, `GET /device` y la cola (`queue`) responden en el formato de Z-API. Consulta [Estado de la instancia](/es/z-api/instance/status), [Datos de la instancia](/es/z-api/instance/me), [Dispositivo](/es/z-api/instance/device) y [Cola](/es/z-api/instance/queue-count).
