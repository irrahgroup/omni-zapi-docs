## Conceptos

Método que informa si un número tiene cuenta de WhatsApp. Envía el teléfono en la ruta, en el formato DDI DDD NÚMERO, como `551199999999`.

Úsalo para validar números, generalmente en formularios. Para verificar varios números a la vez, usa [Verificación en lote](/es/z-api/contacts/get-iswhatsapp-batch).
