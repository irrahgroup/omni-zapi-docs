## Conceptos

Método que elimina contactos de WhatsApp de la lista de contactos del celular. La ruta usa el método `DELETE` con cuerpo: envía una lista JSON con los teléfonos, en el formato DDI DDD NÚMERO.

Como en Z-API, la ruta solo funciona para cuentas de WhatsApp que ya recibieron la actualización necesaria. Sin eso, la operación no se completa.
