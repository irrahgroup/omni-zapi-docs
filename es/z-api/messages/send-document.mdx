## Conceptos

Método para enviar documentos. La extensión del archivo debe indicarse en el path de la URL (p. ej.: `/send-document/pdf`). Puedes enviarlos mediante **URL** o mediante **Base64**.

<Warning>
  Al enviarlo en Base64 es obligatorio incluir el prefijo con el tipo de documento, por ejemplo: `data:application/pdf;base64,`.
</Warning>
