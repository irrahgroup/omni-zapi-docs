Envía un documento, por **URL** o por **Base64**. La extensión del archivo va en el path (`/send-document/pdf`).

<Note>
  <ZapiResponseText lang="es" />
</Note>

<Note>
  Los límites de tamaño y de formato siguen las políticas de WhatsApp. Consulta la [documentación oficial de WhatsApp](https://developers.facebook.com/docs/whatsapp/api/media).
</Note>

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `400` | `invalid document: must be a valid URL or base64 data URI` | El campo no es una URL `http`/`https` ni un Base64 con prefijo `data:` |
| `422` | `message has no content this route can send` | El cuerpo no trae el campo del archivo ni `message`, por lo que no hay contenido para enviar |
| `422` | `message editing is not supported for this channel` | `editDocumentMessageId` o `editMessageId` en el cuerpo |
