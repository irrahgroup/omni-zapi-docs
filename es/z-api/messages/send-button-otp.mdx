## Conceptos

Método para enviar un mensaje de texto con un botón para copiar un código, como un código de verificación. Funciona en canales de **WhatsApp Web**.

## Campos

| Campo | Uso |
|---|---|
| `phone` | Obligatorio. Teléfono del destinatario. |
| `message` | Obligatorio. Texto del mensaje. |
| `code` | Obligatorio. Código que se copia al hacer clic en el botón. |

Los campos `image` y `buttonText` de Z-API no se envían al destinatario.

<Warning>
  En WhatsApp Oficial, el botón de copiar código solo existe en plantillas de autenticación. Consulta las [Limitaciones de la API Oficial](/es/z-api/limitations).
</Warning>
