## Conceptos

En Z-API, para responder citando un mensaje, se incluye el atributo `messageId` en el body de un endpoint de envío.

<Warning>
  En la versión Z-API Compatibilidad, la respuesta con cita **no está disponible**, ni en WhatsApp Oficial ni en WhatsApp Web. El atributo `messageId` se acepta en los envíos, pero el mensaje llega al cliente como un mensaje normal, sin citar el original.
</Warning>

Si estás migrando desde Z-API, el envío con `messageId` no falla: la API responde con normalidad y el mensaje se entrega, solo que sin la cita. No uses este campo esperando que el cliente vea el mensaje original.

En las rutas [`send-reaction`](/es/z-api/messages/send-reaction) y [`send-remove-reaction`](/es/z-api/messages/send-remove-reaction), el `messageId` tiene otra función: identifica el mensaje que recibe la reacción, y sigue valiendo.

## Cómo citar un mensaje

Para enviar un mensaje citando otro, usa las rutas de mensajes de Omni Z-API con el campo `content.messageIdReply`. La cita funciona en el canal de WhatsApp Oficial (Meta Cloud API). Consulta [Responder citando un mensaje](/es/messages/introduction#responder-citando-un-mensaje).

El atributo `privateAnswer` de Z-API (respuesta privada en grupos) no es compatible con la API oficial y no está disponible en esta versión.
