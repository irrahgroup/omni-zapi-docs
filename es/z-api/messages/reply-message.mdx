<Warning>
  La respuesta con cita **todavía no está disponible**. El atributo `messageId` se acepta en los
  envíos, pero el mensaje llega al cliente como un mensaje normal, sin citar el original. Consulta
  las [Limitaciones de la API Oficial](/es/z-api/limitations).
</Warning>

## Conceptos

En Z-API, para responder citando un mensaje, se incluye el atributo `messageId` en el body de un endpoint de envío. Esta versión todavía no envía esa cita a WhatsApp.

Si estás migrando desde Z-API, el envío con `messageId` no falla: la API responde con normalidad y el mensaje se entrega, solo que sin la cita. No uses este campo esperando que el cliente vea el mensaje original.

<Warning>
  El atributo `privateAnswer` de Z-API (respuesta privada en grupos) **no es compatible** con la API oficial y no está disponible en esta versión.
</Warning>
