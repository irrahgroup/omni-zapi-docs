## Conceptos

Método para enviar vídeos. Puedes enviarlos mediante **URL** o mediante **Base64**.

<Warning>
  Al enviarlo en Base64 es obligatorio incluir el prefijo con el tipo de vídeo, por ejemplo: `data:video/mp4;base64,`.
</Warning>
