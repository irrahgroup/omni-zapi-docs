## Conceptos

Método para enviar mensajes con botón de pago mediante Pix. El destinatario recibe un botón que, al pulsarlo, copia la clave Pix.

Los tipos de clave admitidos son: **CPF**, **CNPJ**, **PHONE**, **EMAIL** y **EVP** (clave aleatoria).
