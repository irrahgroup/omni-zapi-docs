<Warning>
  Esta ruta **no envía** en Z-API Omni. Siempre responde `422`. Consulta [Limitaciones y rechazos](/es/z-api/limitations#envío-rechazado).
</Warning>

En Z-API, esta ruta envía un mensaje con un botón que copia la clave Pix. WhatsApp Oficial no tiene ese botón.

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `422` | `pix button is not supported for this channel` | Siempre. No se envía nada |
