## Conceptos

Método para enviar mensajes con botones de selección rápida. El destinatario puede elegir entre las opciones que se le presentan, que funcionan como respuesta al mensaje.

Opcionalmente puedes incluir una **imagen** o un **vídeo** junto a los botones añadiendo el campo `image` o `video` dentro de `buttonList`.

<Warning>
  Envía solo `image` o `video`, nunca los dos a la vez.
</Warning>
