Quita la reacción de un mensaje. Indica su `messageId`. Cualquier `reaction` enviada en el cuerpo se ignora.

<Note>
  <ZapiResponseText lang="es" />
</Note>

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `422` | `messageId is required to react to a message` | `messageId` ausente o vacío |
