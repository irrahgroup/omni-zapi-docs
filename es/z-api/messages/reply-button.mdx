## Conceptos

Método para responder un botón de un mensaje enviado con [lista de botones](/es/z-api/messages/send-button-list), como si el contacto lo hubiera pulsado. Envía en `messageId` el mensaje que contiene los botones y en `responseButtonId` el id del botón elegido.

El `messageId` es el id del mensaje en Omni Z-API, y `phone` es obligatorio, como en Z-API, pero no se usa. En la respuesta, `messageId` e `id` repiten el `messageId` enviado.
