## Conceptos

Método para responder una lista de opciones, como si el contacto hubiera tocado una de las opciones. Envía en `messageId` el mensaje de la lista y en `responseOptionId` el `id` de la opción elegida, el mismo que se definió para ella al armar la lista.

El `messageId` es el id del mensaje en Omni Z-API, y `phone` es obligatorio, como en Z-API, pero no se usa. En la respuesta, `messageId` e `id` repiten el `messageId` enviado.
