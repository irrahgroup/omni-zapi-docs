## Conceptos

Método para reenviar un mensaje existente. Envía en `messageId` el mensaje que se reenviará y en `phone` el destinatario.

El `messageId` es el id del mensaje en Omni Z-API (en el formato por defecto del webhook, `message._id`). Los atributos `messagePhone` y `delayMessage` se aceptan por compatibilidad con Z-API y no se usan: el mensaje se encuentra por el `messageId`. En la respuesta, `messageId` e `id` traen el id del nuevo mensaje, y `zaapId` es un identificador generado por la API.
