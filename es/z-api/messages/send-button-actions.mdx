## Conceptos

Método para enviar mensajes con botones de acción. Se aceptan dos tipos de botón:

- **URL**: abre un enlace
- **REPLY**: respuesta rápida

## Reglas de los botones

- `message` es obligatorio y tiene hasta 1.024 caracteres.
- El mensaje lleva **un** botón `URL`, con `url` `http` o `https`, **o** hasta tres botones `REPLY`. Los dos tipos no van en el mismo mensaje.
- `label` es obligatorio y tiene hasta 20 caracteres.
- `id` tiene hasta 256 caracteres. Sin `id`, el botón recibe su posición en la lista, a partir de `"1"`.
- En los botones `REPLY`, `label` e `id` no se repiten.
- `title` y `footer` tienen hasta 60 caracteres y solo van con el botón `URL`.

<Warning>
  El botón `CALL` y el botón de copiar código (URL `https://www.whatsapp.com/otp/code/...`) no se aceptan.
</Warning>

## Errores

Un mensaje fuera de las reglas se rechaza con `422` y no se envía:

| Situación | `error` |
|---|---|
| Botón `CALL` | `call button is not supported for this channel` |
| Botón de copiar código | `copy button is not supported for this channel` |
| `URL` y `REPLY` en el mismo mensaje | `URL and REPLY buttons cannot be sent together on this channel` |
| Más de un botón `URL` | `only one URL button is supported for this channel` |
| Más de tres botones `REPLY` | `buttonActions must have at most 3 REPLY buttons` |
| `title` o `footer` con botones `REPLY` | `title and footer with REPLY buttons are not available for this channel yet` |
| `buttonActions` ausente o vacío | `buttonActions is required` |

Los demás límites también responden `422`, con el campo en el mensaje. Por ejemplo: `buttonActions[0].label must be at most 20 characters`.
