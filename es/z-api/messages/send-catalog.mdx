## Conceptos

Método para enviar el catálogo de productos de WhatsApp Business. El destinatario recibe una tarjeta con un enlace para ver el catálogo completo.

<Warning>
  Esta función requiere una cuenta de **WhatsApp Business** con el catálogo y los productos configurados.
</Warning>
