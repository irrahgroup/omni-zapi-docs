<Warning>
  Esta ruta **no envía** en Z-API Omni. Siempre responde `422`. Consulta [Limitaciones y rechazos](/es/z-api/limitations#envío-rechazado).
</Warning>

En Z-API, esta ruta envía el catálogo de productos de WhatsApp Business. El envío por esta ruta todavía no está disponible. Para el envío de catálogo por la API nativa, consulta [Enviar catálogo](/es/messages/send-catalog).

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `422` | `catalog message is not available for this channel yet` | Siempre. No se envía nada |
