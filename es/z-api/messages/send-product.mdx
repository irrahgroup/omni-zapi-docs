## Conceptos

Método para enviar productos registrados en el catálogo de WhatsApp Business. El producto debe estar registrado previamente en el catálogo de la cuenta business.

El `productId` se puede obtener mediante la API de listado de productos o a través del webhook de productos.

<Warning>
  Esta función requiere una cuenta de **WhatsApp Business** con el catálogo configurado.
</Warning>
