<Warning>
  Esta ruta **no envía** en Z-API Omni. Siempre responde `422`. Consulta [Limitaciones y rechazos](/es/z-api/limitations#envío-rechazado).
</Warning>

En Z-API, esta ruta envía un producto del catálogo de WhatsApp Business. El envío por esta ruta todavía no está disponible. Para el envío de producto por la API nativa, consulta [Enviar producto](/es/messages/send-product).

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `422` | `product message is not available for this channel yet` | Siempre. No se envía nada |
