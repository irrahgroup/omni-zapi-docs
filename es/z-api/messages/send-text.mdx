### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `400` | `message is required` | `message` ausente, vacío o solo con espacios |
| `400` | `mentions are only allowed in groups` | `mentioned` en una conversación que no es de grupo |
| `422` | `message editing is not supported for this channel` | `editMessageId` en el cuerpo |
