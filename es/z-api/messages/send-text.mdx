## Conceptos

Método para enviar mensajes de texto simples. Admite el formato de WhatsApp, emojis y saltos de línea.

Para añadir saltos de línea al mensaje, usa cualquiera de estos formatos: `\n`, `\r`, `\r\n` o `%0a`.
