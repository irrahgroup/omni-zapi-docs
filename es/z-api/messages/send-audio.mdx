## Conceptos

Método para enviar mensajes de audio. Puedes enviarlos mediante **URL** o mediante **Base64**. El audio se envía como mensaje de voz en WhatsApp.

<Warning>
  Al enviarlo en Base64 es obligatorio incluir el prefijo con el tipo de audio, por ejemplo: `data:audio/mpeg;base64,`.
</Warning>
