## Conceptos

Método para enviar varios contactos en un solo mensaje. No hace falta que los contactos estén guardados en tu agenda: basta con indicar el nombre y el teléfono de cada uno. Funciona en canales de **WhatsApp Oficial** y en canales de **WhatsApp Web**.

## Campos

| Campo | Uso |
|---|---|
| `phone` | Obligatorio. Teléfono del destinatario. |
| `contacts` | Obligatorio. Lista de los contactos a enviar. |
| `contacts[].contactName` | Obligatorio. Nombre del contacto. |
| `contacts[].contactPhone` | Teléfono del contacto. Obligatorio cuando no se envía `contactPhones`. |
| `contacts[].contactPhones` | Lista de teléfonos del contacto. Cuando se envía, vale en lugar de `contactPhone`. |

<Warning>
  Cada elemento de `contacts` usa los nombres `contactName`, `contactPhone` y `contactPhones`, los mismos de [`send-contact`](/es/z-api/messages/send-contact). Los nombres `name`, `phones` y `businessDescription` del envío de múltiples contactos de Z-API no se leen.
</Warning>
