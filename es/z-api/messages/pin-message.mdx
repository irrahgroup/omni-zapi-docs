## Conceptos

Método para fijar o desfijar un mensaje en una conversación. En `messageAction`, envía `pin` para fijar o `unpin` para desfijar.

Al fijar, `pinMessageDuration` define por cuánto tiempo el mensaje queda fijado: `24_hours`, `7_days` o `30_days`. Al desfijar, este campo no se usa. El `messageId` es el id del mensaje en Omni Z-API, y `phone` es obligatorio, como en Z-API, pero no se usa. En la respuesta, `messageId` e `id` repiten el `messageId` enviado.
