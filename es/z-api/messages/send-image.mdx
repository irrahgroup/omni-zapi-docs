## Conceptos

Método para enviar imágenes. Puedes enviar la imagen de dos formas: mediante **URL** o mediante **Base64**.

<Warning>
  Al enviarla en Base64 es obligatorio incluir el prefijo con el tipo de imagen, por ejemplo: `data:image/png;base64,`. Para validarlo, pega el Base64 completo en la barra de direcciones del navegador y comprueba que la imagen se muestra correctamente.
</Warning>
