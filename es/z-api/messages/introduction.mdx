## Conceptos

Las rutas de esta sección envían mensajes en el formato de Z-API, por canales WhatsApp Oficial (`META_WHATSAPP`) con suscripción activa. Un canal de otro tipo, o sin suscripción activa, recibe `422`.

<Warning>
  Por la API oficial de WhatsApp, un mensaje libre solo se puede enviar con la ventana de conversación de 24 horas abierta. La ventana se abre cuando el **cliente te envía un mensaje**. Fuera de ella, la conversación solo empieza con una [plantilla aprobada por Meta](/es/z-api/messages/send-template). Consulta [Ventana de conversación](/es/conversation-window).
</Warning>

## Formato de la solicitud

- El cuerpo es JSON (`Content-Type: application/json`) o `application/x-www-form-urlencoded`.
- `phone` es obligatorio en todo envío: el teléfono del destinatario, con código de país y de área, por ejemplo `5511999999999`.
- `delayMessage` y `delayTyping` aceptan hasta 15. Un valor mayor vale 15.
- `customId` es un identificador tuyo, devuelto en la respuesta.

## Respuesta de la API

Un envío aceptado responde `200` con la misma estructura de Z-API:

```json
{
  "zaapId": "3999984263738042930CD6ECDE9VDWSA",
  "messageId": "D241XXXX732339502B68",
  "id": "D241XXXX732339502B68"
}
```

El `customId` vuelve en la respuesta cuando lo envías. `id` tiene el mismo valor que `messageId`.

<Note>
  La estructura de la respuesta es la de Z-API: el código que ya procesa estos campos sigue funcionando.
</Note>

### Guarda el messageId

Guarda el `messageId` devuelto: es el identificador del mensaje en las operaciones que se refieren a él, como [enviar reacción](/es/z-api/messages/send-reaction).

## Errores comunes

Valen para toda ruta de envío. Las rutas de [instancia](/es/z-api/instance/status) y los rechazos de ruta usan el mismo cuerpo, `{"error": "<texto>"}`.

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `400` | `invalid image: must be a valid URL or base64 data URI` | El campo del archivo no es una URL `http`/`https` ni un Base64 con prefijo `data:`. Lo mismo vale para `invalid video`, `invalid ptv`, `invalid audio` y `invalid document` |
| `400` | `Authorization invalid` o `<ip> not allowed` | Falla de [autenticación](/es/z-api/authentication) |
| `400` | `ec2Id is empty for this instance` | El canal todavía no terminó de aprovisionarse |
| `404` | `instance not found` | El `id` o el `token` del path no existe |
| `422` | `instance middleware is not META_WHATSAPP` | El canal no es WhatsApp Oficial |
| `422` | `instance subscription is not active` | El canal no tiene suscripción activa |
| `422` | `Authorization invalid` o `You are blocked, contact support.` | Falla de [autenticación](/es/z-api/authentication) |
| `422` | `message has no content this route can send` | El cuerpo no genera ningún mensaje que la ruta envíe |
| `422` | `this channel does not support sending messages yet` | El tipo del canal todavía no tiene entrega |
| `502` | `failed to send message` | La plataforma de mensajes no aceptó el envío. Intenta de nuevo en unos instantes |

## Formato de texto

Puedes dar formato al texto de los mensajes con los caracteres especiales de WhatsApp:

| Formato | Sintaxis | Resultado |
|---|---|---|
| **Negrita** | `*texto*` | **texto** |
| _Cursiva_ | `_texto_` | _texto_ |
| ~~Tachado~~ | `~texto~` | ~~texto~~ |
| `Monoespaciado` | `` ```texto``` `` | `texto` |
