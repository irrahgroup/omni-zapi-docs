Envía una plantilla aprobada. Es la forma de iniciar una conversación fuera de la ventana de 24 horas. Consulta [Plantillas](/es/templates/introduction).

<Note>
  <ZapiResponseText lang="es" />
</Note>

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `400` | `template name is required` | `template.name` ausente o vacío |
| `400` | `template language code is required` | `template.language.code` ausente o vacío |
