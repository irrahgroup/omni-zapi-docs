Envía una reacción con emoji a un mensaje. Indica el `messageId` del mensaje que recibe la reacción.

<Note>
  <ZapiResponseText lang="es" />
</Note>

### Errores

| Status | Respuesta `error` | Cuándo |
|---|---|---|
| `400` | `phone is required` | `phone` ausente o vacío |
| `422` | `messageId is required to react to a message` | `messageId` ausente o vacío |
| `422` | `reaction is required` | `reaction` ausente o vacío |
| `422` | `reaction must be an emoji` | `reaction` tiene espacios, letras o es demasiado largo para ser un emoji |
