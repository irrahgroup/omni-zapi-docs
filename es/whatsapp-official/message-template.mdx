## ¿Qué es una plantilla?

Una **plantilla** (plantilla de mensaje) es un mensaje registrado previamente y aprobado por Meta. Sirve para **iniciar o reanudar una conversación** cuando no hay una ventana abierta.

**Ejemplos de uso:**

- Confirmación de pedido
- Recordatorio de cita
- Aviso de entrega
- Aviso de cobro
- Recuperación de una conversación
- Confirmación de una reserva

**Las plantillas pueden contener:**

- Texto
- Imágenes
- Vídeos
- Documentos
- Botones
- Variables personalizadas

## ¿Qué ocurre después de enviar una plantilla?

Depende de la respuesta del cliente.

### Si el cliente responde

En cuanto el cliente responde a la plantilla:

- Se abre una nueva ventana de 24 horas
- Tu empresa vuelve a poder enviar mensajes normales con normalidad

```
Ventana cerrada
       ↓
Envío de la plantilla
       ↓
El cliente responde
       ↓
Nueva ventana de 24 horas
       ↓
Mensajes libres de nuevo
```

### Si el cliente no responde

Si el cliente no responde:

- La ventana sigue cerrada
- No podrás enviar mensajes normales
- Tendrás que enviar otra plantilla cuando tenga sentido hacerlo

<Note>
  Para entender mejor cómo funciona la ventana de atención, consulta la página sobre la [ventana de 24 horas](/es/whatsapp-official/24h-window).
</Note>

## Categorías de plantillas

Cada plantilla pertenece a una categoría definida por Meta.

<CardGroup cols={3}>
  <Card title="Marketing" icon="bullhorn">
    Se usa para promociones, ofertas, difusión de productos y campañas.

    **Ejemplo:** «Aprovecha un 20 % de descuento en toda la tienda hasta el domingo.»
  </Card>
  <Card title="Utilidad" icon="bell">
    Se usa para información solicitada o relacionada con una compra o un servicio: confirmación de pedido, actualización de la entrega, envío de una factura, confirmación de pago o cambio de una cita.
  </Card>
  <Card title="Autenticación" icon="lock">
    Se usa para validar la identidad del usuario: código OTP, código de inicio de sesión o autenticación en dos pasos.
  </Card>
</CardGroup>
