## Concepto

El enlace de invitación del grupo.

<Note>
  El **canal** debe ser administrador del grupo; si no, `422` `provider_error` con el mensaje `The channel is not an admin of this group, so WhatsApp does not return its invite link. Make the channel an admin of the group, or ask a group admin for the link.`
</Note>
